# 기업 코테 유형 분석

## KOSCOM

코스콤 사전 테스트 예시와 본 알고리즘 기출을 모아 두고, 백준과 프로그래머스에서 비슷한 문제를 찾아 푸는 공간입니다. 아래 내용은 직접 리서치한 기록을 정리한 것입니다.

### 빈출로 본 경향

2023 상반기에는 구현 3문제가 나왔다.

### 복기 메모

블로그에 남은 기억이다. 문제 원문과 정답 조건은 확인되지 않았다.

#### 2024 신입

1번

- 해시셋, 구현
- 해시셋, 이분 탐색, 구현. 이분 탐색은 쓰지 않아도 풀 수 있어 보인다
- 완전 탐색에 가깝다
- 쉬운 편이지만 함정에 빠지기 쉽다

2번

- 구현 비중이 크다
- 처리할 조건이 여러 개라 실수할 지점이 많다
- 조각으로 나누면 쉽고, 그 조각을 이어 붙인 문제다



#### 2025년 4월 상반기

문제 1. 화단의 꽃

- 꽃 종류는 1개 이상 1000개 이하
- 화단 길이는 1 이상 1000 이하
- 같은 종류의 꽃은 연속해서 둘 수 없다
- 조건을 만족하도록 바꿀 때, 바꾸는 최소 횟수를 구한다
- 이후 조건이 더 붙었고, 그 부분은 기억나지 않는다

문제 2. 원형 기차

- 기차 칸은 1번부터 1000번까지
- 한 칸에서 옆 칸으로 이동하는 시간은 1
- 기차는 원형이다. 1000번 다음은 1번이고, 1번 이전은 1000번이다
- 출발지와 도착지가 주어질 때, 출발지에서 도착지까지 가는 최소 거리를 구한다


#### 2026년 4월 상반기
문제 1

- 주요 업무와 보조 업무가 있고
- 업무 종류, 주어진 시간, 처리되는 시간 해서 2차원 배열이 주어짐
- 주어진 시간이 제일 빠른거 → 주요 업무 → 보조 업무(처리 되는 시간 순)
- 처리된 업무 순서대로 출력 *1차원 배열

문제 2

정수 x(1 <= x <= 1,000,000,000)가 주어진다. 양의 정수 y를 선택하여 |x-y| = s(x)+s(y)를 만족하면 x를 |x-y|로 바꿀 수 있다. 이 연산을 0번 이상 반복하여 만들 수 있는 값 중 최솟값을 구하는 함수를 작성하라. 여기서 s(n)은 n의 각 자리수의 합이다.
