## 1. 이 계획이 따르는 규칙 (코스콤 v3 R1~R10 번역)

| # | 규칙 | 이 계획에서의 뜻 |
|---|---|---|
| R1 | **읽기 전에 코드부터.** | Java 문법 블로그 정독 금지. **치트시트 1장(부록 A)만** 보고 바로 코드트리 문제를 Java로 제출한다. |
| R2 | **모르는 채로 틀려도 된다.** | 컴파일 에러·`NullPointer`는 첫날 정상. 에러 메시지를 보고 고친 뒤, 같은 문제를 D+1에 다시. |
| R3 | **같은 문제를 D+1, D+3에 안 보고.** | 하루에 같은 문제를 3번 몰아 쓰지 않는다. |
| R4 | **하루에 한 유형만 파지 않는다.** | 매일: Java 새 유형 소수 + 어제 Java 재작성 + Oracle SQL. |
| R5 | **15분 룰.** | 새 Java API(예: `PriorityQueue`)는 15분 시도 → 부록 A 예제 **읽고 덮고 처음부터**. 문법서 챕터로 도망가지 않는다. |
| R6 | **핵심 3유형은 3번 성공.** | ① HashMap/정렬 구현 ② 격자·BFS ③ Oracle 그룹별 최댓값 행(+JOIN). |
| R7 | **저녁 것은 다음날 아침 10분.** | 23:30 취침. 밤샘 금지. |
| R8 | **블라인드 재작성이 시험장.** | Python 답을 옆에 두고 번역만 하면 안 된다. **덮고 Java만.** |
| R9 | **실수는 종류로 적는다.** | `==` vs `.equals`, `int` 오버플로, `LIMIT` 습관, `ROWNUM` 위치 등 → §5. |
| R10 | **시험 직전 10분 걱정 쓰기.** | §6. |

> 한 줄: **Python 실력을 Java 손가락으로 옮긴다. Oracle은 MySQL 습관만 고친다. 4시간을 넘기지 않는다.**

## 부록 B — Oracle ↔ MySQL (이 시험용만)

| 하고 싶은 일 | MySQL (쓰지 말 것) | Oracle (쓸 것) |
|---|---|---|
| 상위 N행 | `ORDER BY … LIMIT N` | `SELECT * FROM (… ORDER BY …) WHERE ROWNUM <= N` |
| NULL 대체 | `IFNULL(c,'x')` | `NVL(c,'x')` |
| 날짜 포맷 | `DATE_FORMAT(d,'%Y-%m-%d')` | `TO_CHAR(d,'YYYY-MM-DD')` |
| 시(0~23) | `HOUR(d)` | `TO_CHAR(d,'HH24')` |
| 문자열 연결 | `CONCAT(a,b)` | `a \|\| b` (또는 `CONCAT`) |
| 더미 행 | (불필요) | `FROM DUAL` |
| 조건 분기 | `IF` / `CASE` | `CASE` (또는 `DECODE`) |

**그룹별 최댓값 행 틀 (Oracle도 동일 사고):**

```sql
SELECT A.*
FROM TABLE A
JOIN (
  SELECT KEY_COL, MAX(VAL) AS MV
  FROM TABLE
  GROUP BY KEY_COL
) B
  ON A.KEY_COL = B.KEY_COL
 AND A.VAL = B.MV;
```
