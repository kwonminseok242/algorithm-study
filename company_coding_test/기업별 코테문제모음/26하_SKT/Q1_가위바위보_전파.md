# Q1. 가위바위보 상태 전파

## 문제 조건

- 노드 `n`개, **방향 간선 `n-1`개**
- 각 노드는 가위 / 바위 / 보 중 하나의 타입을 가짐
- A → B 간선이 있고 A의 타입이 B의 타입을 **이기면**, 1초 뒤 B는 A의 타입으로 바뀜
- 상태 변화는 **모든 노드에서 동시에** 일어남
- `time`초가 지난 뒤 각 노드의 타입을 반환

### 예시로 확인할 규칙
A → B → C → A 순환이고 각자가 다음 노드를 이기는 타입이면,
1초 뒤 A, B, C **모두** 동시에 바뀐다.

---

## 접근

**동시 갱신(simultaneous update)** 이 핵심. 원본 배열을 읽으면서 같은 배열에 쓰면
같은 턴에 이미 바뀐 값이 다른 노드 계산에 섞여 들어간다.

```python
def solve(n, types, edges, time):
    beats = {'S': 'P', 'R': 'S', 'P': 'R'}   # beats[X] = X가 이기는 타입

    current = types[:]
    for _ in range(time):
        nxt = current[:]                      # 반드시 복사본에 기록
        for a, b in edges:
            if beats[current[a]] == current[b]:
                nxt[b] = current[a]
        current = nxt                         # 한 턴이 끝난 뒤에 교체
    return current
```

> 실전에서 사용한 `new_arr = arr[:]` 방식이 정확히 이 처리에 해당한다. **맞는 판단.**

---

## 체크포인트

### 1. 여러 노드가 한 노드를 가리킬 때 충돌하지 않는가

**충돌하지 않는다.**
가위바위보에서 타입 X를 이기는 타입은 **정확히 하나**뿐이다.
따라서 B를 이기는 선행 노드들은 전부 같은 타입이므로 `nxt[b]`에 서로 다른 값이 쓰일 일이 없다.

이 성질을 모르면 "여러 개가 동시에 가리키면 어떡하지"에서 불필요하게 복잡해진다.

### 2. 간선이 `n-1`개라는 조건의 의미

트리라는 뜻이 **아니다.** 방향 그래프이고 연결 보장도 없다.

가능한 형태:
- 트리 컴포넌트 + 사이클 컴포넌트 혼재
- 사이클이 여러 개 (예: `n=7` → 3-사이클 2개 + 고립 노드 1개 = 6간선)
- 고립 노드 (들어오는 간선 없음 → 영원히 안 바뀜)

### 3. `time` 범위 — 유일한 실패 지점

현재 풀이는 `O(간선수 × time)`.
`time`이 `10^9` 규모면 **시간 초과**.

---

## time이 클 때의 보완 (주기 탐지)

전체 상태를 튜플로 만들어 딕셔너리에 넣고 **같은 상태가 다시 나오는 시점**을 찾는다.

```python
def solve_large_time(n, types, edges, time):
    beats = {'S': 'P', 'R': 'S', 'P': 'R'}

    current = tuple(types)
    seen = {current: 0}
    history = [current]

    for t in range(1, time + 1):
        nxt = list(current)
        for a, b in edges:
            if beats[current[a]] == current[b]:
                nxt[b] = current[a]
        current = tuple(nxt)

        if current in seen:
            cycle_start = seen[current]
            cycle_len = t - cycle_start
            idx = cycle_start + (time - cycle_start) % cycle_len
            return list(history[idx])

        seen[current] = t
        history.append(current)

    return list(current)
```

### 왜 주기가 반드시 생기는가
- 상태 공간이 유한(`3^n`)하므로 언젠가 반복된다.
- 실제로는 훨씬 빨리 수렴한다. 트리 부분은 전파가 끝나면 고정되고,
  사이클은 모든 간선이 "이기는 간선"일 때만 값이 회전한다.
- 사이클 길이 `L`이 회전할 때, 타입 정합성 때문에 `L`은 3의 배수여야 한다.

## 결론

| 항목 | 판정 |
|---|---|
| 동시 갱신 (`arr[:]`) | ✅ 정확 |
| 다중 선행 노드 충돌 처리 | ✅ 문제 없음 (구조적으로 안전) |
| `time`이 작은 경우 | ✅ 통과 |
| `time`이 큰 경우 | ⚠️ 시간 초과 위험 → 주기 탐지 필요 |
