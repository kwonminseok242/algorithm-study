# 문제 3: 원 포함 관계 집합 개수 세기

## 문제 설명

- 원 `n`개가 주어진다. 각 원은 중심 좌표 `(x, y)`와 반지름 `r`로 표현된다.
- 원들 중 일부를 골라 집합을 만든다. 집합은 아래 조건을 만족해야 한다.
  1. 집합 안의 **어느 두 원을 뽑아도** 한 원이 다른 원을 기하학적으로 완전히 포함해야 한다. (내접도 포함으로 본다)
  2. 집합의 크기는 **2개 이상**이다.
- 하나의 원이 여러 집합에 속해도 된다. 일부 원이 어느 집합에도 속하지 않아도 된다.

## 구하는 값

- 조건을 만족하는 **집합의 총 개수**. (mod 없음)

## 제약 조건

- `n`은 그리 크지 않다.
- 좌표와 반지름은 모두 정수.
- 같은 원(중심과 반지름이 모두 같은 원)은 없다.
- 내접도 포함으로 취급한다.

## 정답 풀이

### 1. 포함 관계 판정

원 A가 원 B를 포함할 조건:

```
r_A > r_B  이고  (x_A - x_B)^2 + (y_A - y_B)^2 <= (r_A - r_B)^2
```

- 제곱근을 쓰지 않고 제곱 값끼리 비교하므로 정수만으로 정확히 판정할 수 있다.
- 같은 원이 없으므로 반지름이 같은 두 원은 서로 포함할 수 없다. 그래서 `r_A > r_B`를 엄격하게 둬도 된다.
- 내접은 포함이므로 거리 비교는 `<=`.
- 반지름만 비교하면 안 된다. 반지름이 더 커도 중심이 멀면 포함되지 않는다.

### 2. 체인 구조

- 포함 관계는 전이적이다. A⊃B이고 B⊃C이면 A⊃C.
- 따라서 "어느 두 원을 뽑아도 포함 관계"인 집합은, 바깥쪽부터 안쪽으로 한 줄로 늘어놓을 수 있는 원들의 모음(체인)과 같다.
- 체인의 어떤 부분집합도 다시 체인이다.

### 3. DP

- 반지름 내림차순으로 정렬하면 포함하는 쪽이 항상 앞에 온다.
- `f[i]` = **원 `i`가 가장 바깥쪽이고 크기가 2 이상인 집합의 개수**. 0으로 초기화한다.

```
f[i] = sum( f[j] + 1  for j in (i가 포함하는 원들) )
```

- `+1`: `{i, j}` 딱 그 두 원으로만 이루어진 집합.
- `f[j]`: `j`가 가장 바깥인 집합 하나하나의 앞에 `i`를 붙인 집합들. `i ⊃ j`이고 `j`가 그 집합의 모든 원을 포함하므로, 전이성에 의해 `i`는 그 집합의 모든 원을 포함한다. 따라서 조건이 유지되고, 개수 그대로 더하면 된다.
- 계산 순서: `f[j]`가 먼저 확정되어 있어야 하므로 **뒤에서부터(안쪽 원부터)** 채운다.

### 4. 중복이 생기지 않는 이유

`i`를 가장 바깥으로 하는 집합은 "`i`를 제외한 나머지 중 가장 큰 원이 누구인가"로 분류된다. 어떤 집합이든 이 값이 하나로 정해지므로 분류가 겹치지 않고 빠지는 집합도 없다.

- 예: `A`를 가장 바깥으로 하는 집합 중
  - `B`가 그다음으로 큰 원: `{A,B}`, `{A,B,C}` → `f[B] + 1 = 2`개
  - `C`가 그다음으로 큰 원: `{A,C}` → `f[C] + 1 = 1`개
- `{A,B,C}`는 B 쪽에서만 세어진다. C 쪽은 "A 다음으로 큰 원이 C"인 집합만 센다.

### 5. 답

- `f`를 "크기 2 이상 집합"으로 정의했으므로 **`sum(f)`가 곧 답**이다. (`n`을 뺄 필요 없음)

## 코드

```python
def solve(circles):
    n = len(circles)
    circles.sort(key=lambda c: -c[2])   # 반지름 내림차순
    f = [0] * n

    for i in range(n - 1, -1, -1):       # 안쪽(반지름 작은) 원부터 확정
        xi, yi, ri = circles[i]
        for j in range(i + 1, n):
            xj, yj, rj = circles[j]
            if ri > rj and (xi - xj) ** 2 + (yi - yj) ** 2 <= (ri - rj) ** 2:
                f[i] += f[j] + 1

    return sum(f)
```

## 검증 포인트

1. 점화식은 `f[i] += f[j] + 1`. `f[j]`만 더하면 0에서 시작한 값이 계속 0이 된다.
2. DP는 반드시 뒤에서부터 채운다. 앞에서부터 돌리면 `f[j]`가 아직 최종값이 아니다.
3. 내접은 포함이므로 거리 비교는 `<=`. `<`를 쓰면 내접 케이스를 놓친다.
4. 포함 판정은 제곱근 없이 제곱 비교로 한다. 정수 정확도 측면에서 안전하다.
5. 답이 지수적으로 커질 수 있다. Python은 큰 정수를 그대로 다루지만, C++이나 Java라면 `n` 범위에 따라 `long long`을 넘는지 확인해야 한다.

## 시간복잡도

- 정렬: `O(n log n)`
- 쌍 비교 및 DP: `O(n^2)`
- 전체: `O(n^2)`. `n`이 크지 않으므로 충분하다.

## 테스트 케이스

입력은 `(x, y, r)` 리스트. 아래 값은 모든 부분집합을 직접 검사하는 브루트포스와 대조해 확인했다.

| 2 | `(0,0,1), (10,0,1)` | 0 | 서로 떨어진 원 |
| 3 | `(0,0,3), (0,0,2), (0,0,1)` | 4 | 동심원 3개 체인 |
| 4 | `(0,0,3), (2,0,1)` | 1 | 내접이 포함으로 인정됨 (거리 2 = 3-1) |
| 5 | `(0,0,2), (1,0,2)` | 0 | 반지름이 같으면 포함 불가 |
| 6 | `(0,0,3), (3,0,2)` | 0 | 일부만 겹치는 경우 |
| 7 | `(0,0,10), (5,0,2), (-5,0,2)` | 2 | 작은 원 둘은 서로 포함 안 함 |

| 9 | `(0,0,4), (0,0,3), (0,0,2), (0,0,1)` | 11 | 동심원 4개 (2^4 - 4 - 1) |

| 11 | `(0,0,10), (1,0,6), (2,0,3), (2,0,1), (20,0,4), (20,0,2)` | 12 | 큰 체인(원 4개) + 별도 체인(원 2개) |

## 케이스별 `f` 값 변화

반지름 내림차순으로 정렬한 인덱스 순서이고, `i`를 맨 뒤(가장 안쪽)부터 앞으로 채운다. 초기값은 모두 0.

### 케이스 3: `(0,0,3), (0,0,2), (0,0,1)`

인덱스: 0=A(r3), 1=B(r2), 2=C(r1). 초기 `f = [0, 0, 0]`.

| 단계 | 비교 | 포함 여부 | 변화 | f |
|---|---|---|---|---|
| i=2 (C) | 비교할 j 없음 | - | - | [0, 0, 0] |
| i=1 (B) | j=2 (C) | 2>1, 거리² 0 ≤ 1 → 포함 | f[1] += f[2]+1 = 1 | [0, 1, 0] |
| i=0 (A) | j=1 (B) | 3>2, 거리² 0 ≤ 1 → 포함 | f[0] += f[1]+1 = 2 | [2, 1, 0] |
| i=0 (A) | j=2 (C) | 3>1, 거리² 0 ≤ 4 → 포함 | f[0] += f[2]+1 = 1 → 3 | [3, 1, 0] |

`sum(f) = 4`. 집합: `f[1]`은 `{B,C}`, `f[0]`은 `{A,B}`, `{A,B,C}`, `{A,C}`.

### 케이스 4: `(0,0,3), (2,0,1)`

인덱스: 0=A(r3), 1=B(r1). 초기 `f = [0, 0]`.

| 단계 | 비교 | 포함 여부 | 변화 | f |
|---|---|---|---|---|
| i=1 (B) | 비교할 j 없음 | - | - | [0, 0] |
| i=0 (A) | j=1 (B) | 3>1, 거리² 4 ≤ (3-1)² = 4 → 포함 (내접, 등호 성립) | f[0] += f[1]+1 = 1 | [1, 0] |

`sum(f) = 1`. 거리² 4와 `(r_A - r_B)²` 4가 같아서 `<=` 덕분에 내접이 포함으로 잡힌다. `<`였다면 답이 0이 되어 틀린다.

### 케이스 7: `(0,0,10), (5,0,2), (-5,0,2)`

인덱스: 0=P(r10), 1=S1(5,0,r2), 2=S2(-5,0,r2). 초기 `f = [0, 0, 0]`. 반지름이 같은 S1, S2는 정렬이 안정적이라 입력 순서가 유지된다.

| 단계 | 비교 | 포함 여부 | 변화 | f |
|---|---|---|---|---|
| i=2 (S2) | 비교할 j 없음 | - | - | [0, 0, 0] |
| i=1 (S1) | j=2 (S2) | 반지름 2>2 거짓 → 포함 불가 | 변화 없음 | [0, 0, 0] |
| i=0 (P) | j=1 (S1) | 10>2, 거리² 25 ≤ 64 → 포함 | f[0] += f[1]+1 = 1 | [1, 0, 0] |
| i=0 (P) | j=2 (S2) | 10>2, 거리² 25 ≤ 64 → 포함 | f[0] += f[2]+1 = 1 → 2 | [2, 0, 0] |

`sum(f) = 2`. 집합: `{P,S1}`, `{P,S2}`. S1과 S2는 서로 포함하지 않아서 `{P,S1,S2}`는 만들어지지 않고, DP도 `f[1]`, `f[2]`가 0이라 자동으로 걸러낸다.

### 케이스 8: `(0,0,10), (5,0,2), (-5,0,2), (5,0,1)`

인덱스: 0=P(r10), 1=S1(5,0,r2), 2=S2(-5,0,r2), 3=T(5,0,r1). 초기 `f = [0, 0, 0, 0]`.

| 단계 | 비교 | 포함 여부 | 변화 | f |
|---|---|---|---|---|
| i=3 (T) | 비교할 j 없음 | - | - | [0, 0, 0, 0] |
| i=2 (S2) | j=3 (T) | 2>1이지만 거리² 100 > 1 → 포함 불가 | 변화 없음 | [0, 0, 0, 0] |
| i=1 (S1) | j=2 (S2) | 반지름 같음 → 포함 불가 | 변화 없음 | [0, 0, 0, 0] |
| i=1 (S1) | j=3 (T) | 2>1, 거리² 0 ≤ 1 → 포함 | f[1] += f[3]+1 = 1 | [0, 1, 0, 0] |
| i=0 (P) | j=1 (S1) | 10>2, 거리² 25 ≤ 64 → 포함 | f[0] += f[1]+1 = 2 | [2, 1, 0, 0] |
| i=0 (P) | j=2 (S2) | 10>2, 거리² 25 ≤ 64 → 포함 | f[0] += f[2]+1 = 1 → 3 | [3, 1, 0, 0] |
| i=0 (P) | j=3 (T) | 10>1, 거리² 25 ≤ 81 → 포함 | f[0] += f[3]+1 = 1 → 4 | [4, 1, 0, 0] |

`sum(f) = 5`. 집합으로 풀어쓰면 다음과 같다.
- `f[1] = 1`: `{S1,T}`
- `f[0] = 4`: `{P,S1}`, `{P,S1,T}`, `{P,S2}`, `{P,T}`

S2와 T 사이를 주목할 것. 반지름은 2>1이라 조건을 통과하지만 중심 거리가 멀어서(거리² 100) 포함이 안 되고, 그래서 `{S2,T}`나 `{P,S2,T}`는 만들어지지 않는다. 반지름만 비교하면 놓치는 부분이다.
