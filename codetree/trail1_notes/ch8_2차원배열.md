## 1. 소문자를 대문자로 — `upper()` / `lower()`

### 핵심 요약

- 문자열에 **`.upper()`** 를 붙이면 **모든 소문자가 대문자로** 바뀐다. 반대는 **`.lower()`**.

  ```python
  'apple'.upper()      # 'APPLE'
  'APPLE'.lower()      # 'apple'
  ```

- ⚠️⭐ **원본은 절대 바뀌지 않는다.** 바뀐 **새 문자열을 돌려줄 뿐**이다.

  ```python
  s = 'apple'
  s.upper()            # 'APPLE' 이 만들어졌지만 버려짐
  print(s)             # apple   ← 그대로!

  s = s.upper()        # ⭐ 다시 담아야 바뀐다
  print(s)             # APPLE
  ```

- 알파벳이 아닌 글자(숫자, 공백, 기호, 한글)는 **그대로 통과**한다. 에러가 나지 않는다.

  ```python
  'a1 b2!'.upper()     # 'A1 B2!'
  '사과 apple'.upper() # '사과 APPLE'
  ```

### 칸이 없다 — `문자열.upper()`

```
  문자열 . upper ( )
    ↓       ↓     ↓
  바꿀 대상  뭘 할지  괄호는 비워 둔다
```

- `len(s)`, `int(s)` 처럼 **괄호 안에 넣는 게 아니라**, 바꿀 문자열 **뒤에 점을 찍어** 쓴다.
- `upper(s)` 라고 쓰면 **NameError** — `upper`라는 함수는 따로 없다.
- 괄호는 비어 있어도 **반드시 붙인다.** `s.upper` 는 함수 자체를 가리킬 뿐 실행되지 않는다.

### 같이 알아 둘 4형제

| 쓰는 법 | 하는 일 | 예시 (`'hello world'`) |
| --- | --- | --- |
| `.upper()` | 전부 대문자 | `'HELLO WORLD'` |
| `.lower()` | 전부 소문자 | `'hello world'` |
| `.capitalize()` | **첫 글자만** 대문자, 나머지는 소문자 | `'Hello world'` |
| `.title()` | **단어마다** 첫 글자를 대문자 | `'Hello World'` |

- 추가로 `.swapcase()` 는 대소문자를 **서로 뒤집는다** — `'aB'.swapcase()` → `'Ab'`.

### 확인만 하고 싶을 때 — `isupper()` / `islower()`

```python
'A'.isupper()        # True
'a'.isupper()        # False
'a'.islower()        # True
'1'.isupper()        # False  ← 알파벳이 아니면 둘 다 False
```

- `.isalpha()`(알파벳인가), `.isdigit()`(숫자인가)도 같은 집안이다.

### 예시 코드

**① 입력받은 단어를 대문자로 출력하기**

```python
s = input()
print(s.upper())
```

**② 대소문자 구분 없이 비교하기 ⭐**

```python
a = input()          # Apple
b = input()          # APPLE

if a == b:
    print('Yes')     # 실행 안 됨 — 'Apple' != 'APPLE'
if a.upper() == b.upper():
    print('Yes')     # ⭐ 양쪽을 같은 쪽으로 맞춰 놓고 비교
```

- **"같은 글자인가?"** 를 물을 땐 **양쪽 다** `.upper()`(또는 둘 다 `.lower()`)로 맞춘다.

**③ 소문자만 대문자로, 대문자는 그대로 두기**

```python
s = input()
result = ''
for c in s:
    if c.islower():
        result += c.upper()
    else:
        result += c
print(result)
```

- 사실 `.upper()` 는 대문자를 건드리지 않으므로 `print(s.upper())` 한 줄이면 끝난다.
  위 코드는 **"조건을 걸어 일부만 바꾸는 틀"** 로 기억해 두면 변형 문제에 쓸 수 있다.

**④ 한 글자씩 뒤집어 출력 — `.swapcase()` 를 직접 만들기**

```python
s = input()                       # aBcD
result = ''
for c in s:
    if c.isupper():
        result += c.lower()
    else:
        result += c.upper()
print(result)                     # AbCd
```

**⑤ 리스트 전체를 대문자로 — `map` / 컴프리헨션 (ch7 복습)**

```python
arr = ['a', 'b', 'c']

print([x.upper() for x in arr])          # ['A', 'B', 'C']
print(list(map(str.upper, arr)))         # ['A', 'B', 'C']   ⭐ 괄호 없이 str.upper
```

- `map`의 왼쪽은 **함수 이름만** 들어가므로 `str.upper` 라고 적는다(`x.upper()` 꼴은 못 쓴다).

**⑥ 2차원 배열(문자 격자)을 전부 대문자로**

```python
n, m = map(int, input().split())
grid = [list(input()) for _ in range(n)]

for i in range(n):
    for j in range(m):
        grid[i][j] = grid[i][j].upper()

for row in grid:
    print(''.join(row))
```

- 2차원 배열에서는 **`grid[i][j]` 한 칸마다** 씌우고, 출력할 땐 `''.join(row)` 로 줄을 합친다.

### 아스키 코드로 직접 바꾸기 — `ord()` / `chr()` (ch6 연계)

- 대문자와 소문자는 아스키 코드가 **정확히 32만큼** 떨어져 있다.

  ```
  'A' = 65 ... 'Z' =  90
  'a' = 97 ... 'z' = 122
         └ 차이는 항상 32 ┘
  ```

- 그래서 **소문자 → 대문자는 `-32`**, **대문자 → 소문자는 `+32`** 다.

  ```python
  c = 'a'
  print(chr(ord(c) - 32))      # 'A'
  print(chr(ord('A') + 32))    # 'a'
  ```

- ⭐ 실전에서는 **`.upper()` 를 쓰는 게 맞다.** 이 방법은 **"b는 a로부터 몇 칸 뒤인가"**
  (`ord(c) - ord('a')`) 처럼 **알파벳을 번호로 바꿔야 하는 문제**를 위해 알아 둔다.

  ```python
  ord('c') - ord('a')          # 2   ← c는 세 번째 알파벳(0부터 세서 2)
  chr(ord('a') + 2)            # 'c' ← 번호를 다시 글자로
  ```

### 주의할 점

- ⚠️⭐ **`s.upper()` 만 쓰면 아무것도 안 바뀐다.** 문자열은 **수정이 불가능(immutable)** 해서
  반드시 **`s = s.upper()`** 처럼 다시 담거나 바로 `print()` 해야 한다.
  - 이건 `.upper()` 만의 성질이 아니다. `.lower()`, `.replace()`, `.strip()` 모두 같다.
  - 반대로 **list는 수정이 가능**해서 `arr.sort()` 처럼 **원본을 직접 바꾸는** 함수도 있다.
    "문자열 함수는 새로 돌려준다 / list 함수는 자기를 고친다"로 구분해 두면 편하다.
- ⚠️ `s[0] = 'A'` 같은 **글자 하나 바꿔치기는 TypeError**다. (list는 된다.)
  - 한 글자만 바꾸고 싶으면 **슬라이싱으로 이어 붙이거나** `list(s)` 로 바꿔서 작업한다.

  ```python
  s = 'apple'
  s = s[0].upper() + s[1:]     # 'Apple'   ⭐ 자주 쓰는 패턴
  ```

- ⚠️ `upper(s)` / `s.upper` 는 둘 다 틀렸다. **`s.upper()`** — 점 찍고, 괄호까지.
- ⚠️ `.capitalize()` 는 **나머지를 소문자로 내려 버린다.** `'hELLO'.capitalize()` → `'Hello'`.
  첫 글자만 올리고 나머지는 **그대로** 두고 싶으면 위의 `s[0].upper() + s[1:]` 를 쓴다.
- ⚠️ 비교할 때 **한쪽만** `.upper()` 하면 의미가 없다. `'Apple'.upper() == 'apple'` 은 False.
  **양쪽을 같은 쪽으로** 맞춰야 한다.
- ⚠️ 숫자에는 쓸 수 없다. `123.upper()` 는 **AttributeError** — 문자열에만 붙는 함수다.
  입력을 `int()` 로 받아 놓고 `.upper()` 를 붙이지 않도록 주의.

## 2. 지그재그로 채우기 — 카운터 하나 + 방향 뒤집기

### 핵심 요약

- **"채우는 순서"와 "출력하는 순서"는 다르다.** 이게 이 문제의 전부다.
  - 채우기는 **세로(열 단위)** 로 지그재그, 출력은 **가로(행 단위)**.
  - 순서가 다르니 **바로 출력할 수 없다.** → **2차원 배열에 다 채워 놓고, 마지막에 출력**한다.
- ⭐ 넣을 숫자는 **카운터 변수 하나**(`num = 0`)로 충분하다.
  **칸 하나 채울 때마다 `num += 1`** — 그게 끝이다. 시작·끝을 계산할 필요가 없다.
- ⭐ 지그재그 = **갈 칸은 똑같고 방향만 뒤집히는 것**이다.
  - **짝수 열(0, 2, 4…) → 위에서 아래로**
  - **홀수 열(1, 3, 5…) → 아래에서 위로**
- 그래서 반복문은 **딱 두 겹**이다. **바깥이 열, 안쪽이 행** (출력과 반대 순서).

**N = 4, M = 5 일 때 (문제 그림)**

```
    j=0  j=1  j=2  j=3  j=4
i=0  0 ↓  7 ↑  8 ↓ 15 ↑ 16 ↓
i=1  1 ↓  6 ↑  9 ↓ 14 ↑ 17 ↓
i=2  2 ↓  5 ↑ 10 ↓ 13 ↑ 18 ↓
i=3  3 ↓  4 ↑ 11 ↓ 12 ↑ 19 ↓
     내려감 올라감 내려감 올라감 내려감
```

- 열 하나를 다 채우면 **`N`개**를 쓴 것이므로, 각 열의 **시작 숫자는 `j * N`** 이다.
  (0열 → 0, 1열 → 4, 2열 → 8 … 그림의 0, 4, 8, 12, 16과 일치)

### 접근 순서 — 이렇게 생각하면 안 헤맨다

1. **그림을 좌표표로 옮긴다** (ch6에서 한 것과 같다). `(i, j)`에 어떤 수가 들어가는가?
2. **채우는 순서대로 손가락으로 따라가 본다.** → "0,1,2,3 아래로 / 4,5,6,7 위로 / …"
3. 따라간 순서를 그대로 **반복문으로 옮긴다.** 손가락이 열 단위로 움직였으면 **바깥 `for`가 열**.
4. 숫자는 **생각하지 않는다.** 칸을 밟을 때마다 **`num += 1`** 이면 저절로 맞는다.
5. 방향이 바뀌는 곳에만 **`if`를 하나** 넣는다.

### 예시 코드

**① 가장 기본 — 행 번호를 뒤집기 ⭐ (가장 권장)**

```python
n, m = map(int, input().split())
answer = [[0] * m for _ in range(n)]

num = 0
for j in range(m):                      # 바깥 = 열
    for i in range(n):                  # 안쪽 = 행
        row = i if j % 2 == 0 else n - 1 - i    # ⭐ 홀수 열은 뒤집어서
        answer[row][j] = num
        num += 1

for row in answer:
    print(*row)
```

- `n - 1 - i` 는 **"위에서 i번째"를 "아래에서 i번째"로 바꾸는 공식**이다.
  `i = 0 → n-1`(맨 아래), `i = n-1 → 0`(맨 위).

**② 같은 생각, `range`를 뒤집는 방식**

```python
num = 0
for j in range(m):
    if j % 2 == 0:
        rows = range(n)                 # 0, 1, 2, 3   (아래로)
    else:
        rows = range(n - 1, -1, -1)     # 3, 2, 1, 0   (위로)

    for i in rows:
        answer[i][j] = num
        num += 1
```

- `range(n-1, -1, -1)` = **"n-1부터 0까지 거꾸로"**. 끝은 포함되지 않으므로 **`-1`** 까지 적는다.

**③ 배열 없이 바로 출력 — 공식으로 ⭐**

```python
n, m = map(int, input().split())

for i in range(n):
    print(*[j * n + (i if j % 2 == 0 else n - 1 - i) for j in range(m)])
```

- `(i, j)` 칸의 값 = **`j * n` (그 열의 시작 숫자) + `열 안에서 몇 번째인가`**.
- 규칙을 식으로 바꿀 수 있으면 **배열조차 필요 없다.** 다만 ①이 떠올리기 쉽고 실수도 적다.

### 오류 정리 — 내가 쓴 코드가 안 됐던 이유

```python
for i in range(m):              # ① i인데 열을 돈다 (이름부터 헷갈림)
    for j in range(n):
        if i % 2 == 0:          # ② 홀수 열(else)이 없다 → 절반이 안 채워짐
            for k in range(start*i, end*n):   # ③ 반복문이 3겹
                answer[j][i] = k              # ④ 같은 칸을 몇 번이나 덮어씀
                start += 1
                end += 1
```

- **① 이름이 꼬였다.** 관습은 **`i` = 행, `j` = 열**이다. 여기서는 `i`가 열이라
  `answer[j][i]` 라고 거꾸로 써야 했고, 그 순간부터 머릿속이 헝클어진다.
  → **바깥 변수가 열이면 `for j in range(m)` 이라고 이름부터 맞춰 쓴다.**
- **② `else`가 없다.** 지그재그는 **두 가지 경우**인데 짝수 열만 처리했다.
  홀수 열은 `0`인 채로 남는다.
- **③⭐ 반복문이 한 겹 더 많다.** 칸은 `n * m`개인데 반복은 `m × n × (k의 범위)`번 돈다.
  → **"칸 하나에 반복 한 번"** 이 맞는지 세어 보는 습관. 2차원 배열은 **두 겹이면 끝**이다.
- **④ 숫자를 "범위"로 생각했다.** `start`, `end` 로 구간을 계산하려 했지만,
  숫자는 **그냥 0부터 하나씩 늘어날 뿐**이다. → **카운터 하나 `num += 1`**.
- 그래서 `answer[j][i] = k` 가 **같은 칸을 k번 덮어쓰고**, 마지막 값만 남는다.

**고치면 이렇게 짧아진다**

```python
num = 0
for j in range(m):
    for i in range(n):
        answer[i if j % 2 == 0 else n - 1 - i][j] = num
        num += 1
```

### 변형 — 가로로 지그재그라면?

```python
num = 0
for i in range(n):                      # 바깥 = 행
    for j in range(m):
        col = j if i % 2 == 0 else m - 1 - j
        answer[i][col] = num
        num += 1
```

- **바깥/안쪽만 바꾸고, 뒤집는 대상을 열로** 바꾸면 된다. 뼈대는 완전히 같다.

### 주의할 점

- ⚠️⭐ **2차원 배열은 `answer[행][열]`.** 바깥 `for`가 열이어도 **인덱스 순서는 안 바뀐다.**
  `answer[i][j]` 가 아니라 **`answer[row][j]`** 인지 항상 확인.
- ⚠️⭐ **`[[0] * m] * n` 으로 만들면 안 된다.** 모든 행이 **같은 리스트**가 되어
  한 칸만 바꿔도 모든 줄이 함께 바뀐다. 반드시 **`[[0] * m for _ in range(n)]`**.

  ```python
  bad = [[0] * 3] * 2
  bad[0][0] = 9
  print(bad)      # [[9, 0, 0], [9, 0, 0]]   ← 둘 다 바뀜!
  ```

- ⚠️ 거꾸로 도는 `range`는 **끝을 하나 더 내려 적는다.** `range(n-1, -1, -1)`.
  `range(n-1, 0, -1)` 이라고 쓰면 **0번 행을 빠뜨린다.**
- ⚠️ `num`은 **반복문 밖에서 한 번만** 초기화한다. 안에서 초기화하면 매 열마다 0으로 돌아간다.
  (ch7의 **"플래그는 밖에서 한 번만"** 과 똑같은 실수다.)
- ⚠️ 숫자는 **0부터** 시작한다. `num = 1` 로 두면 전부 1씩 밀린다.
- ⚠️ 출력은 **`print(*row)`** — 공백으로 구분된다. `print(row)` 는 `[0, 7, 8]` 처럼 대괄호가 찍힌다.
- ⚠️ 출력 반복문은 **채우는 반복문이 전부 끝난 뒤**에. 안에 넣으면 아직 0인 칸이 찍힌다.

## 3. 대각선으로 채우기 — `i + j`가 같은 칸끼리 묶기

### 핵심 요약

- ⭐⭐ **한 대각선 위의 칸들은 `i + j`가 모두 같다.** 이 한 줄이 문제의 전부다.
  - ch6에서 `i + j == N-1` 이 ／ 모양이었던 것과 같은 성질이다. 그 선을 **전부**로 넓힌 것.
- 그러니 **대각선 번호를 `d = i + j` 라고 이름 붙이고**, `d`를 **0부터 차례로** 돌면
  채우는 순서가 그대로 나온다.
- 2번(지그재그)과 **뼈대가 똑같다.** 바깥 반복문이 열(`j`)에서 **대각선(`d`)** 으로 바뀌었을 뿐이고,
  숫자는 여전히 **카운터 하나 `num += 1`**, 채운 뒤 **마지막에 출력**한다.
- 대각선의 개수는 **`n + m - 1`** 개다. (`d`는 0 ~ `n+m-2`)

**N = 4, M = 6 일 때 (문제 그림)**

```
      j=0  j=1  j=2  j=3  j=4  j=5
i=0    1    2    4    7   11   15
i=1    3    5    8   12   16   19
i=2    6    9   13   17   20   22
i=3   10   14   18   21   23   24
```

**각 칸의 `i + j`를 적어 보면** — 같은 수끼리가 곧 하나의 대각선이다.

```
      j=0  j=1  j=2  j=3  j=4  j=5
i=0    0    1    2    3    4    5
i=1    1    2    3    4    5    6
i=2    2    3    4    5    6    7
i=3    3    4    5    6    7    8      ← d는 0부터 8까지, 총 4+6-1 = 9개
```

| `d` | 들어가는 칸 | 채워지는 숫자 |
| --- | --- | --- |
| 0 | (0,0) | 1 |
| 1 | (0,1) → (1,0) | 2, 3 |
| 2 | (0,2) → (1,1) → (2,0) | 4, 5, 6 |
| 3 | (0,3) → (1,2) → (2,1) → (3,0) | 7, 8, 9, 10 |
| … | … | … |

- 대각선 안에서는 **`i`가 커지는 순서** = **오른쪽 위 → 왼쪽 아래**(그림의 ↙ 화살표)와 일치한다.
- `d`가 정해지면 `i`만 알면 **`j = d - i`** 로 따라온다. **돌릴 변수는 `i` 하나**다.

### 접근 순서 — 모르겠을 땐 이 순서로

1. **그림을 좌표표로 옮긴다.** (2번과 똑같은 첫 단계)
2. **"같이 채워지는 칸들"의 공통점을 찾는다.** 세로줄이면 `j`가 같고, 가로줄이면 `i`가 같고,
   **대각선이면 `i + j`가 같다.** ⭐
3. 그 공통점을 **바깥 반복문**으로 삼는다. (`for d in range(n + m - 1)`)
4. 안쪽은 **그 묶음 안을 훑는다.** `i`를 돌리고 **`j = d - i`** 로 짝을 만든다.
5. ⚠️ **격자 밖으로 나간 칸은 건너뛴다.** (`0 <= j < m` 확인)
6. 숫자는 2번과 같이 **카운터 하나**.

### 예시 코드

**① 가장 기본 — `i`를 다 돌고 범위 밖은 건너뛰기 ⭐ (가장 권장)**

```python
n, m = map(int, input().split())
answer = [[0] * m for _ in range(n)]

num = 1                                 # ⚠️ 이 문제는 1부터 시작
for d in range(n + m - 1):              # 대각선 번호 0, 1, 2, ...
    for i in range(n):                  # 행을 전부 시도해 보고
        j = d - i                       # ⭐ 짝이 되는 열
        if 0 <= j < m:                  # ⚠️ 격자 안일 때만
            answer[i][j] = num
            num += 1

for row in answer:
    print(*row)
```

- **생각할 게 가장 적은 형태**다. "다 시도해 보고 밖이면 버린다"는 2차원 문제의 기본 전략이다.

**② `if` 없이 — `i`의 범위를 정확히 계산하기**

```python
num = 1
for d in range(n + m - 1):
    start = max(0, d - m + 1)           # j가 m을 넘지 않으려면
    end = min(n - 1, d)                 # i가 n을 넘지 않고, j가 0 이상이려면
    for i in range(start, end + 1):
        answer[i][d - i] = num
        num += 1
```

- 헛도는 반복이 없어 빠르지만 **경계 계산이 까다롭다.** 코딩테스트에서는 **①로 충분**하다.
- 실수했을 때 ①은 칸이 비지만, ②는 **범위를 잘못 잡아 조용히 틀린다.**

**③ 화살표가 반대(↗, 왼쪽 아래 → 오른쪽 위)라면**

```python
for d in range(n + m - 1):
    for i in range(n - 1, -1, -1):      # ⭐ i를 거꾸로 돌리면 방향이 뒤집힌다
        j = d - i
        if 0 <= j < m:
            ...
```

**④ 대각선마다 방향이 바뀐다면 (지그재그 대각선)**

```python
for d in range(n + m - 1):
    rows = range(n) if d % 2 == 0 else range(n - 1, -1, -1)
    for i in rows:
        j = d - i
        if 0 <= j < m:
            ...
```

- 2번에서 쓴 **"짝/홀로 방향 뒤집기"** 를 그대로 가져온 것이다. 뼈대는 하나다.

### 반대 방향 대각선은 `i - j`

- ／ 방향(오른쪽 위 ↔ 왼쪽 아래)은 **`i + j`가 일정**.
- ＼ 방향(왼쪽 위 ↔ 오른쪽 아래)은 **`i - j`가 일정**. (ch6의 `i == j`가 `i - j == 0`인 경우)

```
i + j (／ 방향)        i - j (＼ 방향)
 0  1  2  3            0 -1 -2 -3
 1  2  3  4            1  0 -1 -2
 2  3  4  5            2  1  0 -1
```

- ⚠️ `i - j`는 **음수가 된다.** 배열 번호로 쓰려면 **`i - j + (m - 1)`** 로 밀어 올린다.
- **"대각선 = 합(／) 또는 차(＼)가 일정"** — 이 한 쌍으로 외워 두면 대각선 문제는 거의 다 풀린다.

### 주의할 점

- ⚠️⭐ **`if 0 <= j < m` 을 빼먹으면 에러가 안 나고 "조용히" 틀린다.**
  `j`가 `-1`이 되면 파이썬은 **맨 오른쪽 칸**으로 알아듣기 때문이다.
  (`j`가 `m` 이상이면 IndexError가 나서 바로 알 수 있지만, **음수는 경고도 없다.**)

  ```python
  row = [10, 20, 30]
  row[-1]          # 30  ← 에러가 아니라 맨 뒤!
  ```

  → **2차원 배열에서 인덱스를 계산해서 만들었다면, 음수 검사를 항상 같이 한다.**
- ⚠️⭐ 대각선 개수는 **`n + m - 1`**. `n + m`으로 쓰면 빈 대각선을 한 번 더 돌고,
  `max(n, m)`으로 쓰면 **뒤쪽 대각선을 통째로 빠뜨린다.**
- ⚠️ **이 문제는 `num = 1`부터**다. 2번 문제(지그재그)는 0부터였다. **문제마다 다르니 매번 확인.**
- ⚠️ `j = d - i` 이지 `j = i - d` 가 아니다. 헷갈리면 **`d = i + j`에서 이항**해 본다.
- ⚠️ `answer[i][j]` — 인덱스 순서는 역시 **[행][열]**.
- ⚠️ 정사각형(`n == m`)으로만 테스트하면 **`n`과 `m`을 바꿔 써도 통과**한다.
  **직사각형**(예: 4 × 6)으로 한 번 더 확인할 것.

- [ ] 소문자 → 대문자는 **`s.upper()`**, 대문자 → 소문자는 **`s.lower()`**.
- [ ] ⚠️⭐ **원본은 안 바뀐다** — `s = s.upper()` 처럼 **다시 담아야** 한다.
- [ ] 쓰는 법은 `upper(s)` 가 아니라 **`s.upper()`** — 점 찍고 **빈 괄호까지**.
- [ ] 알파벳이 아닌 글자(숫자·공백·한글)는 **그대로 통과**, 에러 없음.
- [ ] 첫 글자만 = `.capitalize()`, 단어마다 = `.title()`, 뒤집기 = `.swapcase()`.
- [ ] ⚠️ `.capitalize()` 는 **나머지를 소문자로 내린다.** 그대로 두려면 `s[0].upper() + s[1:]`.
- [ ] 확인만 할 땐 **`.isupper()` / `.islower()`** (알파벳이 아니면 둘 다 False).
- [ ] ⭐ 대소문자 무시 비교 = **양쪽 다** `.upper()` 로 맞추고 `==`.
- [ ] 리스트 전체는 **`[x.upper() for x in arr]`** 또는 `list(map(str.upper, arr))`.
- [ ] 2차원 격자는 **`grid[i][j].upper()`** 로 한 칸씩, 출력은 `''.join(row)`.
- [ ] 아스키로는 **소문자 −32 = 대문자** — `chr(ord(c) - 32)` (실전은 `.upper()`).
- [ ] ⭐ `ord(c) - ord('a')` 는 **알파벳을 0~25 번호로** 바꾸는 패턴으로 기억.
- [ ] ⚠️ 문자열은 **`s[0] = 'A'` 불가(TypeError)** — 슬라이싱으로 이어 붙이거나 `list(s)`.
- [ ] ⚠️ 문자열 함수는 **새로 돌려주고**, `arr.sort()` 같은 list 함수는 **원본을 고친다.**
- [ ] ⚠️ 숫자에는 못 쓴다 — `int`로 받아 놓고 `.upper()` 붙이면 AttributeError.
- [ ] ⭐ **채우는 순서 ≠ 출력 순서** — 다르면 **배열에 채워 놓고 마지막에 출력**.
- [ ] ⭐ 넣을 숫자는 **카운터 하나** — 칸마다 `num += 1`. 구간 계산은 필요 없다.
- [ ] ⭐ 지그재그 = **갈 칸은 같고 방향만 뒤집힘** — 짝수 열 아래로, 홀수 열 위로.
- [ ] 반복문은 **두 겹이면 충분.** 칸 하나에 반복 한 번인지 세어 본다.
- [ ] 세로 지그재그는 **바깥 `for`가 열**, 안쪽이 행 (출력과 반대).
- [ ] 뒤집기 공식 = **`n - 1 - i`** (위에서 i번째 → 아래에서 i번째).
- [ ] 또는 `range(n - 1, -1, -1)` — ⚠️ 끝을 **`-1`** 까지 적어야 0번이 포함된다.
- [ ] 각 열의 시작 숫자는 **`j * n`** — 공식 한 줄로 배열 없이도 풀린다.
- [ ] ⚠️⭐ 인덱스는 언제나 **`answer[행][열]`** — 바깥 `for`가 열이어도 순서는 그대로.
- [ ] ⚠️⭐ **`[[0] * m] * n` 금지** — 모든 행이 같은 리스트가 된다. 컴프리헨션으로 만들 것.
- [ ] ⚠️ 두 갈래면 **`else`를 빠뜨리지 말 것** — 홀수 열이 0으로 남는다.
- [ ] ⚠️ `num` 초기화는 **반복문 밖에서 한 번만**.
- [ ] 이름은 관습대로 **`i` = 행, `j` = 열** — 꼬이면 거기서부터 틀린다.
- [ ] 가로 지그재그는 **바깥/안쪽만 바꾸고** `m - 1 - j` 로 뒤집으면 끝.
- [ ] ⭐⭐ **대각선 = `i + j`가 같은 칸끼리** (／ 방향). ch6의 `i + j == N-1`의 확장.
- [ ] 반대 방향(＼)은 **`i - j`가 일정** — 음수라서 `+ (m-1)` 로 밀어 쓴다.
- [ ] 바깥 `for`는 **대각선 번호 `d`**, 안쪽은 `i`, 열은 **`j = d - i`** 로 따라온다.
- [ ] ⚠️⭐ 대각선 개수는 **`n + m - 1`** 개.
- [ ] ⚠️⭐ **`if 0 <= j < m` 필수** — `j = -1`은 에러 없이 **맨 오른쪽 칸**이 된다.
- [ ] "다 시도하고 **밖이면 건너뛴다**"가 2차원 문제의 기본 전략.
- [ ] 방향을 뒤집고 싶으면 **`i`를 거꾸로** — `range(n-1, -1, -1)`.
- [ ] 대각선마다 방향이 바뀌면 **`d % 2`로 갈라서** 2번과 똑같이 처리.
- [ ] ⚠️ 시작 숫자 확인 — 이 문제는 **1부터**, 지그재그 문제는 0부터였다.
- [ ] ⚠️ 테스트는 **직사각형(n ≠ m)** 으로 — 정사각형은 n·m을 바꿔 써도 통과한다.
- [ ] 묶음의 공통점을 찾아 **바깥 `for`로 삼는다** — 열이면 `j`, 행이면 `i`, 대각선이면 `i+j`.
