## Part A. Trail 1 — 낯설고 헷갈리는 문법

### A1. `sep` 와 `end` (ch1, ch2, ch5)

```python
print(3, 5, sep="")              # 35       값 "사이"
print(1, 2, 3, sep="-", end="!\n")  # 1-2-3!   print가 "끝날 때"
print(a, b, sep="\n")            # 값마다 줄바꿈
```

- `sep` = 값 **사이**(기본 `" "`), `end` = **맨 끝**(기본 `"\n"`).
- ⚠️ 둘 다 **문자열만** — `sep=\n` 은 SyntaxError, `sep=5` 는 TypeError.
- ⚠️ `end` 는 **그 print 한 번**에만 적용된다. 반복문에서 `end=""` 로 찍었으면 끝나고 `print()` 로 줄을 바꾼다.
- ⚠️ 여러 값을 줄바꿔 찍을 때 쓰는 건 `end` 가 아니라 **`sep="\n"`**.

### A2. 출력 형식 3가지 — `%` / `format()` / f-string (ch1)

| 방법 | 모양 | 소수 둘째 자리 |
| --- | --- | --- |
| `%` 포맷 | `"%d %s" % (a, b)` | `"%.2f" % x` |
| `format()` | `"{0} {1}".format(a, b)` | `"{:.2f}".format(x)` |
| f-string | `f"{a} {b}"` | `f"{x:.2f}"` |

- `%` 는 **타입별 기호**: 정수 `%d`, 실수 `%f`, 문자열 `%s`, 문자 `%c`. 값이 여럿이면 **괄호로 묶는다** `% (a, b)`.
- `format()` 번호는 **0부터**. `"{1} {0}".format(a, b)` 처럼 **순서를 바꿀 수 있다**. 이름도 된다 `"{x}".format(x=a)`.
- ⭐ 공통 구조: **`{무엇을 : 어떻게}`** — 콜론 앞이 값, 뒤가 형식.
- ⚠️ f-string과 `format()` 을 **섞지 않는다** — `f"{}".format(...)` 은 SyntaxError.
- ⚠️ `format()` 에 list를 통째로 넘기면 IndexError. 원소를 하나씩 넘긴다.
- 실전은 f-string. `%` 와 `format()` 은 **읽을 줄만** 알면 된다.

### A3. 숫자 모양 맞추기 (ch1, ch2)

```python
f"{3.10:.2f}"    # '3.10'   자리수 유지
round(3.10, 2)   # 3.1      ⚠️ 끝자리 0이 사라진다
f"{7:02d}"       # '07'     0으로 2칸 채우기 (시각·날짜)
f"{{a}}"         # '{a}'    중괄호를 글자로 찍기
f"{2.675:.2f}"   # '2.67'   ⚠️ 실수 오차 (2.68 아님)
```

- "소수점 n째 자리까지 출력"은 **`round()` 말고 `:.nf`**.
- ⚠️ `int("05")` 는 `5` — 앞의 0이 필요한 값(`09`, `05`)은 **출력만 할 거면 문자열 그대로** 둔다.
- ⚠️ 문자열에 바로 `:.2f` 를 쓰면 ValueError. `float()` 로 바꾼 다음에 형식을 씌운다.

### A4. `%` 의 두 얼굴, `/` 는 항상 실수 (ch3)

- `%` 는 **숫자 사이면 나머지**, **문자열 안이면 출력 형식**.
- `/` 는 나누어떨어져도 **항상 float** (`10 / 2` → `5.0`). 정수가 필요하면 **`//`**.
- 파이썬에 **`avg()` 는 없다** → `sum(arr) / len(arr)`. ⚠️ `sum(a, b)` 가 아니라 **`sum([a, b])`**.

### A5. 조건문의 낯선 함정 (ch4, trail2 ch5)

```python
2 + 6 + 5 if n > 10 else 6       # ⚠️ 거짓이면 6  (앞 전체가 한 덩어리)
2 + 6 + (5 if n > 10 else 6)     # ⭐ 거짓이면 14 (괄호로 끊는다)

if a == 2 or 3:                  # ⚠️ 항상 참 (에러도 안 남)
if a == 2 or a == 3:             # ⭐

print(int(a >= b))               # 참이면 1, 거짓이면 0  (True == 1)
True + True                      # 2
0 or 5                           # 5   ⚠️ and/or 는 True/False가 아니라 "피연산자"를 돌려준다
```

- 삼항 연산자 = **`값1 if 조건 else 값2`** — 조건이 가운데, `else` 생략 불가, 콜론 없음.
- 우선순위: **산술 → 비교 → `not` → `and` → `or`**. `and` = 곱하기, `or` = 더하기로 외운다. 섞으면 괄호.

### A6. `range` 거꾸로 세기 (ch5)

```python
list(range(10, 4, -1))   # [10, 9, 8, 7, 6, 5]   첫 자리가 무조건 시작값
list(range(4, 10, -1))   # []   ⚠️ 에러 없이 0번 반복
```

### A7. `;` · `_` · `pass` / `continue` / `break` (ch4, ch5)

- `;` 는 파이썬에서도 된다 — 한 줄에 여러 문장. 단, `for`·`if` 같은 블록은 못 붙인다. 초기화는 `q, s, t = 0, 1, 1`.
- `_` 는 "이 반복 변수 안 쓴다"는 **관례** — `for _ in range(n)`.
- `pass` = 아무것도 안 함(자리 채우기), `continue` = 이번 회차만 건너뜀, `break` = 반복문 전체 종료.
- ⚠️ **`while` + `continue` 는 무한 루프 주의** — 증가식을 건너뛴다.

### A8. 자릿수 뽑기와 긴 나눗셈 (ch5)

```python
n % 10           # 일의 자리
n // 10 % 10     # 십의 자리
while n > 0:     # 모든 자리
    d = n % 10
    n //= 10
```

- ⚠️ 파이썬 float는 **유효숫자 약 17자리**가 한계. "소수 20자리 출력"이면 `/` 와 `:.Nf` 금지 → **정수로 한 자리씩**:

```python
r = A % B
for _ in range(20):
    r *= 10                     # 0을 내려쓴다
    print(r // B, end="")       # 몫을 찍고
    r %= B                      # 나머지만 남긴다
```

### A9. 아스키 코드 `ord()` / `chr()` (ch6, ch9)

```python
ord('A'), ord('a'), ord('0')     # 65, 97, 48   대소문자 차이는 32
chr(ord('Z') + 1)                # '['   ⚠️ Z 다음은 a가 아니다
ord('5')                         # 53    ⚠️ 숫자 5가 아니다 → int('5')
ord(c) - ord('a')                # 글자를 0~25 번호로
chr((ord(c) - ord('a') + k) % 26 + ord('a'))   # k칸 밀기 (z 다음은 a)
```

- 글자끼리는 **`<`, `>` 로 바로 비교**된다 — `'A' <= c <= 'Z'`.
- ⚠️ **`'A' <= c <= 'z'` 는 틀렸다** — 사이에 `[ \ ] ^ _` 와 백틱이 숨어 있다. 두 구간을 `or` 로 나눈다.
- ⚠️ 문자열 비교는 사전순 — `'10' < '9'` 는 True.

### A13. 찾기 3형제 — 있나 `in` / 어디 `find` / 몇 개 `count` (ch7, ch9)

```python
s = "banana"
s.find("x")            # -1   ⚠️ -1은 참(True)이다 → if s.find(x) != -1
s.index("x")           # ValueError → in으로 먼저 확인
s.count("ana")         # 1    ⚠️ 겹치는 건 안 센다 ("aaa".count("aa") == 1)
```

### A15. `is...()` 함수의 함정 (ch9)

## Part B. Trail 2 — 함수 · 시뮬레이션 II · 격자

### B1. 함수 (ch1)

```python
a, b = map(int, input().split())         # ⭐ tuple(...)로 안 감싸도 된다 (언패킹은 왼쪽의 ,)
n, *rest = [1, 2, 3]                     # n=1, rest=[2, 3]  (항상 list)

def add(a, b, c=0): ...                  # ⭐ 안 넘길 수도 있는 인자는 기본값
def add(a=0, b, c): ...                  # ⚠️ SyntaxError — 기본값 인자는 뒤쪽에
def f(arr=[]): ...                       # ⚠️⚠️ 호출할수록 쌓인다 → arr=None 으로 두고 안에서 []

def add(*args): return sum(args)         # ⭐ 개수를 모를 때. args는 튜플
print_rect(*nums)                        # ⭐ 부를 때 *는 "풀기"  [3, 5] → print_rect(3, 5)
```

- `*` 는 하나의 기호 — **정의할 때는 묶고, 부를 때는 푼다**. `*` 하나 = 튜플, `**` 둘 = 딕셔너리.
- ⭐⭐ **`print()` 는 `None` 을 돌려준다** → `return print(cnt)` 는 cnt를 돌려주지 않는다. **계산은 `return`, 출력은 밖에서**.
- ⚠️ `return` 을 만나면 **함수 전체가 끝난다** (`break` 보다 세다).
- ⚠️⚠️ **바깥·안쪽 루프에 같은 이름(`i`) 금지** — 안쪽이 덮어쓴다. `for num in ...` / `for c in str(num)`.
- ⚠️ "수 하나를 한 번만 세기"는 `continue` 가 아니라 **`break`**. 자릿수에 글자가 있는지는 **`'3' in s`** 한 줄.

### B2. 단락 평가 — 지키는 조건이 왼쪽 (ch5)

```python
if i == 0 or a[i] != a[i-1]:            # ⭐ 범위 or 사용
if len(s) > 0 and s[0] == 'a':          # ⭐ 확인 and 사용
if 0 <= nx < n and 0 <= ny < m and grid[nx][ny] == 1:   # ⭐ 격자 검사의 정석
```

- `A or B` — A가 참이면 B를 **실행조차 안 한다**. `A and B` — A가 거짓이면 B를 안 한다.

- ⭐ `if` 로 막기보다 **`range` 를 좁히기** — `a[i-1]` 이면 `range(1, n)`, `a[i+1]` 이면 `range(n-1)`.

### B3. 연속 구간 세기 — 두 종류를 구분 (ch5)

```python
# ① 이웃 관계 조건 (같은 수 / 증가 / 감소)      → 시작 1, 리셋 1
best = cnt = 1
for i in range(1, n):
    cnt = cnt + 1 if arr[i] > arr[i-1] else 1
    best = max(best, cnt)

# ② 원소 자체 조건 (T 초과 / 짝수 / 양수)       → 시작 0, 리셋 0
best = cnt = 0
for x in arr:
    cnt = cnt + 1 if x > t else 0
    best = max(best, cnt)
```

- ⭐⭐ **조건 한 줄만 바꾸면 된다.** 앞 문제 코드를 복사하면 **없는 조건을 끌고 온다** (어제 T 초과 문제에 증가 조건을 넣은 실수).
- ⚠️ `else` 안에서만 저장하면 **마지막 구간이 빠진다** → **매 칸 `best = max(best, cnt)`** 로 구조적으로 막는다.
- ⚠️ `cnt` 의 **시작값과 리셋값이 다르면 첫 구간만 틀린다**.
- "초과" = `>`, "이상" = `>=`. 문제 제목의 단어를 그대로 옮긴다.

### B4. dx, dy — 방향을 배열로 (ch5, 오답노트)

```python
#     오른쪽 아래 왼쪽  위       (시계 방향)
dxs = [0,    1,    0,   -1]
dys = [1,    0,   -1,    0]
mapper = {'R': 0, 'D': 1, 'L': 2, 'U': 3}   # ⭐ 주석 순서 그대로

d = (d + 1) % 4     # 시계 90도
d = (d + 2) % 4     # 반대 방향
d = (d - 1) % 4     # 반시계 90도  (파이썬은 -1 % 4 == 3)
```

- ⚠️⚠️ 격자에서 **`x` = 행, `y` = 열** — 수학 좌표계와 반대. 오른쪽 = `y + 1`, 아래 = `x + 1`.
- ⚠️ **좌표평면 문제**(N/S/E/W)는 반대로 **위(N)가 `y + 1`**. 문제가 "행·열"인지 "좌표"인지 먼저 읽는다.
- ⭐ 반대쌍 배치 `R D U L` 이면 반대 방향이 `3 - d`. ⚠️ **배열 순서를 바꾸면 공식도 바뀐다**.
- ⭐ 가장 안전한 꼴은 쌍 리스트 `DIRS = [(0,1), (1,0), (0,-1), (-1,0)]`.
- ⚠️ `zip(dxs, dys)` 는 길이가 다르면 **에러 없이 짧은 쪽에 맞춰 자른다**.
- ⚠️ 방향 전환에 **고정값을 대입하면** 두 번째 튕김에서 멈춘다 → 항상 `(d + k) % 4`.

### B5. `dict` 로 글자 → 방향 (ch5)

```python
MOVES = {'R': (0, 1), 'D': (1, 0), 'L': (0, -1), 'U': (-1, 0)}
dx, dy = MOVES[c]          # ⚠️ 없는 key는 KeyError
MOVES.get(c, (0, 0))       # 없으면 기본값
c = input().strip()        # ⚠️ 'R\n'은 'R'이 아니다
```

- ⚠️ `in` 은 **key만 본다**. 둘 다 필요하면 `for k, v in d.items()`.
- `if`/`elif` 네 블록 복붙은 **버그를 네 배로 늘린다** → dict 하나로.

### B6. 이동 시뮬레이션의 순서 (ch5, 오답노트)

```python
nx, ny = x + dxs[d], y + dys[d]     # ① 재 보고
if 0 <= nx < n and 0 <= ny < m:     # ② 갈 자리를 묻고   (⚠️ 지금 자리 x, y 가 아니다)
    x, y = nx, ny                   # ③ 그제야 옮긴다
else:
    d = (d + 2) % 4
```

- ⚠️ 경계는 **`< n`** (`< n - 1` 아님). ⚠️ `n`(행)·`m`(열)은 **①배열 생성 ②범위 검사 ③출력 세 곳에 똑같이**.
- ⚠️⚠️ **벽에 닿은 1초가 "제자리"인지 "뒤집고 한 칸 간다"인지** 지문에서 먼저 읽는다. 모르겠으면 예제에 둘 다 대 본다.
- ⭐ "처음으로 / 몇 초 뒤" 가 보이면 **1칸씩 돌리고 매 칸 확인**. 거리만큼 한 번에 점프하면 중간을 놓친다.
- ⚠️ 0-based 로 바꿨으면 출력 직전에 **`+1`** 로 되돌린다. 변환은 입력 직후·출력 직전 두 군데만.

### B7. 달팽이 채우기 (ch5)

```python
answer = [[0] * n for _ in range(n)]     # ⭐ 답이자 방문 표시 (0 = 아직 안 감)
answer[0][0] = 1
x, y, d = 0, 0, 0
for i in range(2, n * n + 1):
    nx, ny = x + dxs[d], y + dys[d]
    if not (0 <= nx < n and 0 <= ny < n) or answer[nx][ny] != 0:   # ⭐ 범위 검사가 앞
        d = (d + 1) % 4
        nx, ny = x + dxs[d], y + dys[d]
    x, y = nx, ny
    answer[x][y] = i
```

- 규칙을 계산하지 말고 **"막히면 시계로 90도"** 만 굴린다.

### B8. 이중 루프 탈출 (오답노트)

```python
answer = -1
for ...:
    for ...:
        if 찾음:
            answer = t
            break           # ⚠️ 안쪽 하나만 끝난다
    if answer != -1:        # ⭐ 바깥도 끊는다
        break
```

- 더 깔끔한 방법은 **함수로 감싸고 `return`** — 몇 겹이든 한 번에 빠져나온다.
- ⚠️ `dir`, `max`, `min`, `sum`, `list`, `str`, `input` 은 **변수 이름으로 쓰지 않는다** (내장 함수가 가려진다).

## Part D. 제출 전 테스트 입력 고르는 법

예제 하나 통과 ≠ 정답. 노트에서 실제로 버그를 잡아낸 입력들이다.

| 의심되는 버그 | 넣어 볼 입력 |
| --- | --- |
| `a[-1]` 함정 | 첫 원소 == 마지막 원소 — `[1, 2, 1]` |
| 마지막 구간 누락 | 최댓값이 맨 뒤 — `1 2 2 2`, 전부 같음 — `3 3 3 3` |
| 첫 구간 오류 | 전부 증가 — `1 2 3 4` |
| 원소 조건 문제 | 하나도 안 맞는 입력 (답 0), 감소 — `9 8 7` |
| 최댓값 초기값 | 전부 음수 |
| 행·열 뒤바뀜 | 직사각형 격자 (`n != m`) |
| 경계·예외 | `n = 1` |
| 자릿수·369 | 두 자리 — `12`, `33`, `36` |
| 문자열 압축 | 끝 글자가 앞과 다름 — `abcd` |
| 긴 나눗셈 | `1 7` (자릿수가 다른 값) |

> 확신이 안 서면 **완전탐색(이중 반복문)으로 짠 답과 대조**해서 검산한다.

#### E4. A/B 를 소수 20자리까지 (ch5) — 세 번 틀린 문제

```python
    print(r // B, end='')  # ⭐ 몫은 출력하고 버린다
```

#### E13. 369 개수 세기 함수 (ch1)

```python
def count_369(a, b):
    cnt = 0
    for num in range(a, b + 1):              # ⭐ 바깥·안쪽 이름 겹치지 않게
        s = str(num)
        if num % 3 == 0 or '3' in s or '6' in s or '9' in s:
            cnt += 1                         # ⭐ 수 하나당 한 번만 센다
    return cnt                               # ⭐ 값만 돌려준다

a, b = map(int, input().split())
print(count_369(a, b))                       # 1 20 → 9
```

| 내가 쓴 코드 | 무엇이 틀렸나 |
| --- | --- |
| `for i in k:` (바깥도 `i`) | 바깥 `i` 를 덮어써서 `int(k)` 로 되돌려야 했다 |
| 3의 배수 검사가 안쪽 루프에 | 자릿수마다 다시 걸려 `12` 를 두 번 셌다 |
| 마지막 줄 `continue` | 아무 일도 안 한다. 한 번만 세려면 `break` |
| `return print(cnt)` | `None` 을 돌려준다 |

- ⚠️ **한 자리 수로만 테스트하면 안 드러난다** → `33`, `12` 를 넣어 본다.

#### E14. 연속 구간 3문제 (ch5 lesson 1) — 코드는 [B3](#b3-연속-구간-세기--두-종류를-구분-ch5)

| 문제 | 내가 낸 버그 | 잡아내는 입력 | 고친 것 |
| --- | --- | --- | --- |

#### E15. 벽에 닿으면 튕기는 공, t초 뒤 위치 (ch5 lesson 3)

```python
n, t = map(int, input().split())
r, c, d = input().split()
x, y = int(r) - 1, int(c) - 1                   # ⭐ 입력 직후 0-based

dxs = [0, 1, 0, -1]                             # 오른쪽 아래 왼쪽 위
dys = [1, 0, -1, 0]
dir_num = {'R': 0, 'D': 1, 'L': 2, 'U': 3}[d]   # ⭐ if 네 블록 → dict 한 줄

for _ in range(t):                              # ⭐ while + t -= 1 보다 안전
    nx, ny = x + dxs[dir_num], y + dys[dir_num]
    if 0 <= nx < n and 0 <= ny < n:             # ⭐ 갈 자리를 검사
        x, y = nx, ny
    else:
        dir_num = (dir_num + 2) % 4             # 이번 1초는 제자리 (Ⓐ)

print(x + 1, y + 1)                             # ⭐ 출력 직전 1-based
```

- ❌ `if in_range(x, y)` — **지금 자리는 항상 안**이라 벽을 통과하고, 밖에서 얼어붙어 `-1 1` 출력.
- ❌ `else: dir_num = 1` 상수 대입, `'L'` 과 `'U'` 가 둘 다 `3` (블록 복붙), `print(x, y)` 에 `+1` 누락.
- ⚠️⚠️ **벽에 닿은 1초가 제자리(Ⓐ)인지, 뒤집고 한 칸 가는지(Ⓑ) 예제로 먼저 확인.** Ⓑ면 `else` 대신 뒤집은 뒤 무조건 이동.

#### E16. 처음으로 원점에 돌아온 시각 (오답노트) — 좌표평면 문제

```python
DIRS = {'N': (0, 1), 'S': (0, -1), 'E': (1, 0), 'W': (-1, 0)}   # ⭐ 좌표평면은 N 이 y + 1

def solve(moves):
    x = y = t = 0
    for d, dist in moves:
        dx, dy = DIRS[d]
        for _ in range(dist):        # ⭐ 1초 = 1칸 = 확인 1번
            x, y = x + dx, y + dy
            t += 1
            if x == 0 and y == 0:
                return t             # ⭐ 몇 겹이든 한 번에 빠져나온다
    return -1

n = int(input())
moves = []
for _ in range(n):
    d, dist = input().split()
    moves.append((d, int(dist)))
print(solve(moves))
```

- ❌ `x + dx * dist` 로 **거리만큼 점프** — `E 1, W 2, E 1` 에서 2초에 지나간 원점을 놓치고 4초.
- ❌ 안쪽에서만 `break` — 바깥이 계속 돌아 `N1 S1 N1 S1` 에서 2초가 4초로 덮어써진다.
- ❌ `'N': (1, 0)` — 격자 감각으로 x를 건드렸다. 원점 복귀처럼 **대칭인 문제는 우연히 통과**한다.
