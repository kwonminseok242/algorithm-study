## 1. print 함수와 문자열 표현 4가지

### 핵심 요약
- 파이썬에서 출력은 `print()` 함수를 쓴다. 괄호 안에 넣은 값이 화면에 나온다.
- 문자열은 따옴표로 감싸서 나타내며, 방법은 4가지다.

| 방법 | 예시 | 특징 |
|---|---|---|
| 큰따옴표 `"` | `"Hello World"` | 한 줄 |
| 작은따옴표 `'` | `'Hello World'` | 한 줄 |
| 큰따옴표 3개 `"""` | `"""Hello World"""` | **여러 줄** 가능 |
| 작은따옴표 3개 `'''` | `'''Hello World'''` | **여러 줄** 가능 |

### 예시 코드
```python
print("Hello")

print('''
Hello World
Python is fun
''')
```

### 주의할 점
- `"`와 `'`는 기능상 차이가 없다. 여는 따옴표와 닫는 따옴표의 **종류만 같으면** 된다.
- `"Hello'`처럼 섞어 쓰면 에러가 난다.

## 2. 따옴표 충돌과 이스케이프 문자 `\`

### 핵심 요약
- 문자열을 `'`로 감쌌는데 중간에 `'`가 또 나오면, 파이썬은 **어디가 문자열의 끝인지 몰라서** 에러를 낸다.

```python
print('Let's do it')   # ❌ SyntaxError: invalid syntax
```

### 해결 방법 3가지
| 방법 | 코드 | 언제 쓰나 |
|---|---|---|
| ① 다른 따옴표로 감싸기 | `print("Let's do it")` | 문자열 안에 `'` **한 종류만** 있을 때 |
| ② 앞에 `\` 붙이기 (이스케이프) | `print('Let\'s do it')` | `"`와 `'`가 **둘 다** 있을 때도 가능 ⭐ |
| ③ 따옴표 3개로 감싸기 | `print('''Let's do it''')` | 가능은 하지만 ②를 꼭 알아둘 것 |

출력 결과는 모두 `Let's do it`

### 주의할 점
- `\`(백슬래시)를 특수문자 앞에 붙이면 **"이건 문법이 아니라 그냥 글자야"** 라는 뜻이 된다. 이를 **이스케이프(escape)** 라고 한다.
- 대부분의 프로그래밍 언어에서 똑같이 쓰는 규칙이라 꼭 기억하기.
- 자주 쓰는 이스케이프 문자:

| 표기 | 의미 |
|---|---|
| `\'` | 작은따옴표 `'` |
| `\"` | 큰따옴표 `"` |
| `\n` | 줄바꿈 (new line) |
| `\t` | 탭 |
| `\\` | 백슬래시 `\` 자체 |

## 3. 여러 줄 출력: `\n`과 `"""`

### 핵심 요약
2줄을 출력하는 방법은 3가지다.

```python
# ① print를 2번 쓰기
print("Hello World")
print("Python is Fun")

# ② \n(줄바꿈 문자) 사용 → print 한 번으로 해결
print("Hello World\nPython is Fun")

# ③ 따옴표 3개로 여러 줄 문자열 만들기
print("""Hello World
Python is Fun""")
```

세 방법 모두 출력:
```
Hello World
Python is Fun
```

### 주의할 점 ⚠️
- `"""` 바로 뒤나 닫는 `"""` 바로 앞에서 **줄을 바꾸면, 그 줄바꿈도 문자열에 포함된다.**

```python
print("""
Hello World
Python is Fun
""")
```
출력:
```
                ← 맨 위에 빈 줄이 생김
Hello World
Python is Fun
                ← 맨 아래에도 빈 줄이 생김
```

- 그래서 딱 맞게 출력하려면 `"""Hello World` 처럼 **따옴표에 바로 붙여서** 쓰고, 끝도 `Python is Fun"""` 처럼 **바로 붙여서** 닫아야 한다.
- 코딩테스트는 출력이 **한 글자라도 다르면 오답**이니 특히 주의!

### ❗ 내가 틀렸던 것: `\n`은 **따옴표 안에서만** 동작한다
변수 두 개를 줄바꿈해서 출력하려고 이렇게 썼더니 에러가 났다.

```python
a = 3
b = "C"

print(a\nb)   # ❌ SyntaxError
```

**왜 안 될까?**
- `\n`은 **문자열 안에 들어 있을 때만** "줄바꿈 문자"라는 뜻이 된다.
- 따옴표 밖에 있는 `\`는 문자열이 아니라 **파이썬 문법 기호**로 읽힌다. 그래서 파이썬은 `a\nb`를 이해하지 못한다.
  (실제 에러 메시지: `SyntaxError: unexpected character after line continuation character`)

**올바른 방법 3가지** (모두 출력은 `3` 다음 줄에 `C`)

```python
# ① sep를 줄바꿈으로 → 값 사이에 \n이 들어감 (가장 깔끔)
print(a, b, sep="\n")

# ② f-string → \n을 따옴표 안에 넣고, 변수는 {}로
print(f"{a}\n{b}")

# ③ print를 두 번
print(a)
print(b)
```

> 💡 정리: **변수는 따옴표 밖(또는 f-string의 `{}` 안)**, **`\n`은 반드시 따옴표 안**.

## 4. 구분자 바꾸기: `sep`

### 핵심 요약
- `print`에 값 여러 개를 `,`로 구분해서 넣으면 **사이에 공백이 하나** 들어가서 출력된다.
- `sep`(separator, 구분자)으로 값 사이에 넣을 문자를 바꿀 수 있다. **기본값은 공백 `" "`** 이다.

### 예시 코드
```python
print(3, 5)             # 3 5
print(3, 5, sep=":")    # 3:5
print(3, 5, sep=" ")    # 3 5   (기본값과 같음)
print(3, 5, sep="")     # 35    (붙여서 출력)
```

### 주의할 점
- `sep`는 **값과 값 사이**에만 들어간다. 맨 앞이나 맨 뒤에는 붙지 않는다.

### ❗ 내가 틀렸던 것: `sep`에는 **문자열만** 들어간다
```python
a = 2
b = 6
a = b              # a에 b의 값(6)을 넣음 → a는 이제 6

print(a, b, sep=\n)     # ❌ SyntaxError
```

**왜 안 될까?**
- `sep`에 넣는 값은 반드시 **문자열**이어야 한다. 그래서 **따옴표로 감싸야** 한다.
- `\n`을 따옴표 없이 쓰면 문자열이 아니게 된다. 파이썬은 `\`를 문법 기호로 읽어서 에러를 낸다. ([3번의 `print(a\nb)` 실수](#-내가-틀렸던-것-n은-따옴표-안에서만-동작한다)와 같은 원인!)

**올바른 코드**
```python
print(a, b, sep="\n")
# 6
# 6
```

**문자열이 아닌 값을 넣으면?**
```python
print(a, b, sep=5)   # ❌ TypeError: sep must be None or a string, not int
print(a, end=5)      # ❌ TypeError: end must be None or a string, not int
```
- 숫자를 넣어도 에러가 난다. `end`도 마찬가지로 **문자열만** 들어간다.
- 숫자를 구분자로 쓰고 싶으면 따옴표로 감싼다: `sep="5"`

> 💡 정리: `sep=" "`, `sep=":"`, `sep="\n"`, `end=" "` → **`sep`와 `end` 뒤에는 무조건 따옴표!**

> 📝 참고: `a = b`는 "a와 b가 같다"가 아니다. **오른쪽 값(b)을 왼쪽 변수(a)에 넣는다**는 뜻이다. 그래서 `a`는 2에서 6으로 바뀌고 `b`는 그대로 6이다.

## 5. 줄바꿈 대신 다른 문자: `end`

### 핵심 요약
- `print`가 끝나면 자동으로 다음 줄로 넘어가는 이유는, `end`의 기본값이 **`\n`(줄바꿈)** 이기 때문이다.
- `end`를 바꾸면 출력이 끝난 뒤 줄바꿈 대신 **다른 문자**를 출력한다.

### 예시 코드
```python
# 기본: 줄 단위로 출력
print(3)
print(5)
# 3
# 5

# 첫 번째 print의 end를 공백으로 변경
print(3, end=" ")
print(5)
# 3 5
```

### 주의할 점
- `end`는 **그 print 한 번**에만 적용된다. 위 예시에서 두 번째 `print(5)`는 기본값(`\n`) 그대로다.
- `sep`와 헷갈리지 않기:
  - `sep` → **한 print 안에서** 값 **사이**에 들어갈 문자
  - `end` → print가 **끝날 때** 마지막에 붙는 문자

```python
print(1, 2, 3, sep="-", end="!\n")   # 1-2-3!
```

## 6. f-string: 문자열 안에 `{}`로 값 넣기

### 핵심 요약
- 문자열 앞에 **`f`** 를 붙이면(`f"..."`), 문자열 안의 **`{}` 속에 변수나 계산식**을 바로 넣을 수 있다.
- `{}` 안의 내용은 **실행된 결과값**으로 바뀌어서 출력된다.
- `f'...'`, `f"""..."""`처럼 다른 따옴표에도 똑같이 쓸 수 있다.

### 예시 코드
```python
name = "철수"
age = 20

# ① 변수 넣기
print(f"이름은 {name}, 나이는 {age}살")   # 이름은 철수, 나이는 20살

# ② 계산식 넣기
a, b = 3, 5
print(f"{a} + {b} = {a + b}")             # 3 + 5 = 8

# ③ 소수점 자리수 지정 (코딩테스트에서 자주 나옴!)
pi = 3.14159
print(f"{pi:.2f}")                        # 3.14  (소수 둘째 자리까지, 반올림)
```

### f를 안 붙이면?
```python
print("{a} + {b}")    # {a} + {b}   ← 중괄호가 그냥 글자로 출력됨
print(f"{a} + {b}")   # 3 + 5
```

### sep/쉼표 방식과 비교
```python
print(a, "+", b, "=", a + b)     # 3 + 5 = 8   (쉼표 → 사이에 공백 자동)
print(f"{a}+{b}={a + b}")        # 3+5=8       (f-string → 쓴 그대로, 공백 조절 자유)
```
- f-string은 **공백을 내가 직접 쓴 대로** 출력하기 때문에, 출력 형식이 까다로운 문제에서 편하다.

### 주의할 점
- `f`는 따옴표 **바로 앞**에 붙여야 한다. (`f "..."`처럼 띄우면 에러)
- 중괄호 자체를 글자로 출력하고 싶으면 **두 번** 쓴다: `f"{{a}}"` → `{a}`
- 바깥 따옴표와 `{}` 안의 따옴표를 **다르게** 쓰는 것이 안전하다.
  ```python
  d = {"key": 1}
  print(f"값: {d['key']}")   # ✅ 바깥 " , 안쪽 '
  ```

## 7. 출력 형식 3가지: `%` 포맷 / `format()` / f-string

### 핵심 요약
변수 값을 원하는 형식에 맞춰 출력하는 방법은 크게 3가지다.

| 방법 | 모양 | 특징 |
|---|---|---|
| ① `%` 포맷 | `"A is %d" % a` | 변수 **타입에 맞는 기호**(`%d`, `%s`…)를 써야 함 |
| ② `format()` | `"A is {0}".format(a)` | 타입 몰라도 됨. `{}`에 **번호나 이름**을 씀 |
| ③ f-string | `f"A is {a}"` | 가장 짧고 직관적 → [6번 참고](#6-f-string-문자열-안에-로-값-넣기) |

---

### ① 변수 포맷(`%d`, `%s` …)과 `%` 사용

- 문자열 안에 **변수 타입에 맞는 포맷 기호**를 쓰고, 문자열 뒤에 `% 변수`를 붙인다.
- 변수가 2개 이상이면 **소괄호 `()`로 묶어서 순서대로** 쓴다.

```python
a = 5
print("A is %d" % a)                    # A is 5

b = "apple"
print("B is %s" % b)                    # B is apple

print("A is %d and B is %s" % (a, b))   # A is 5 and B is apple
```

| 기호 | 타입 | 기억법 |
|---|---|---|
| `%d` | 정수 | **d**ecimal (10진수) |
| `%f` | 실수 | **f**loat |
| `%s` | 문자열 | **s**tring |
| `%c` | 문자 1개 | **c**haracter |

**주의할 점**
- 기호와 변수 타입이 맞지 않으면 에러가 난다. 예: `"%d" % "apple"` → `TypeError`
- 변수 여러 개는 반드시 `% (a, b)`처럼 괄호로 묶는다.
- `%f`는 기본으로 소수 6자리까지 나온다. 자리수를 정하려면 `%.2f`처럼 쓴다.
  ```python
  print("%f" % 3.14159)     # 3.141590
  print("%.2f" % 3.14159)   # 3.14
  ```

---

### ② `format()` 함수 사용

- 문자열 안에서 변수가 들어갈 자리를 **`{}`로 감싸고**, 뒤에 `.format(변수들)`을 붙인다.
- 변수 **타입을 적을 필요가 없다.**
- `{}` 안에는 **번호** 또는 **이름**을 쓸 수 있다.
  - **번호**: `format()`에 넣은 변수의 순서다. **0번부터** 센다.
  - **이름**: 내가 붙인 새 이름을 쓰고, `format(이름=변수)`로 연결한다.

```python
a, b = 5, "apple"

# 번호로 지정
print("A is {0}".format(a))                       # A is 5
print("B is {0}".format(b))                       # B is apple
print("A is {0} and B is {1}".format(a, b))       # A is 5 and B is apple

# 이름으로 지정
print("A is {new_a}".format(new_a=a))             # A is 5
print("A is {new_a} and B is {new_b}".format(new_a=a, new_b=b))
                                                  # A is 5 and B is apple

# 순서를 바꿔서 출력하는 것도 가능!
print("B is {1} and A is {0}".format(a, b))       # B is apple and A is 5
print("B is {new_b} and A is {new_a}".format(new_a=a, new_b=b))
                                                  # B is apple and A is 5
```

**주의할 점**
- 번호는 **1이 아니라 0부터** 시작한다. `format(a, b)`에서 `a`는 `{0}`, `b`는 `{1}`이다.
- `{}` 안에 아무것도 안 쓰면 **넣은 순서대로** 들어간다: `"{} {}".format(a, b)` → `5 apple`
- 소수점 자리수는 `"{:.2f}".format(3.14159)` → `3.14`

---

### 💡 세 방법 한 번에 비교

```python
a, b = 5, "apple"

print("A is %d and B is %s" % (a, b))        # ① % 포맷
print("A is {0} and B is {1}".format(a, b))  # ② format
print(f"A is {a} and B is {b}")              # ③ f-string

# 소수점 둘째 자리
x = 3.14159
print("%.2f" % x)            # 3.14
print("{:.2f}".format(x))    # 3.14
print(f"{x:.2f}")            # 3.14
```

- 결과는 모두 같다. 요즘은 **f-string**을 가장 많이 쓴다.
- 다른 사람 코드나 옛날 코드에는 `%`나 `format()`도 자주 나오니 **읽을 줄은 알아야** 한다.

## 8. 소수점 맞춰 출력하기

### 핵심 요약
- 실수를 출력할 때는 **소수점 몇째 자리까지 출력하라**는 조건이 자주 나온다.
- `.nf`는 **소수점 n째 자리까지 반올림해서 출력**하라는 뜻이다. (`f` = float, 실수)
- 7번에서 배운 출력 형식 3가지에 모두 쓸 수 있다.

### 예시 코드 (소수점 4째 자리까지)
```python
a = 33.567268

print("%.4f" % a)            # ① % 포맷      → 33.5673
print("{0:.4f}".format(a))   # ② format 함수 → 33.5673
print(f"{a:.4f}")            # ③ f-string    → 33.5673
```

### 모양 뜯어보기
```
 "%.4f"      →  %  +  .4f
 "{0:.4f}"   →  {  0번 변수  :  .4f  }
 f"{a:.4f}"  →  {  변수 a    :  .4f  }
                              ↑
                    콜론 : 뒤에 형식을 적는다
```
- `format`과 f-string은 **`{무엇을 : 어떻게}`** 구조다. 콜론 `:` 앞에는 **출력할 값**, 뒤에는 **형식**을 쓴다.
- `format`에서 번호를 생략하고 `"{:.4f}".format(a)`처럼 써도 된다.

### 주의할 점
- 자리수가 모자라면 **0을 채워서** 출력한다.
  ```python
  print(f"{5:.2f}")      # 5.00  (정수도 실수 형식으로 출력됨)
  print(f"{3.1:.3f}")    # 3.100
  ```
- `round()` 함수와 헷갈리지 않기! `round()`는 **값을 바꾸는 함수**라서 끝자리 0이 사라진다.
  ```python
  print(round(3.10, 2))   # 3.1    ← 0이 사라짐 ❌ (출력 형식이 틀릴 수 있음)
  print(f"{3.10:.2f}")    # 3.10   ← 자리수 유지 ✅
  ```
  → **"소수점 n째 자리까지 출력"하라는 문제에서는 `.nf` 형식**을 쓰는 게 안전하다.
- 실수는 컴퓨터 안에서 **아주 조금 오차가 있게 저장**된다. 그래서 끝자리가 5일 때 예상과 다르게 반올림될 수 있다.
  ```python
  print(f"{2.675:.2f}")   # 2.67  (2.68이 아님!)
  ```
  (지금은 "이런 경우도 있다" 정도만 알아두기)

## 🔁 한눈에 복습 (체크리스트)

- [ ] 문자열은 `"`, `'`, `"""`, `'''` 4가지로 감쌀 수 있다. 3개짜리는 여러 줄이 가능하다.
- [ ] 문자열 안에 같은 따옴표가 있으면 에러가 난다. 다른 따옴표로 감싸거나 `\'`처럼 이스케이프한다.
- [ ] `\n`은 줄바꿈 문자라서 print 한 번으로 여러 줄을 출력할 수 있다.
- [ ] `"""` 뒤에서 바로 줄을 바꾸면 위아래에 빈 줄이 생긴다. 따옴표에 붙여서 쓴다.
- [ ] `print(a\nb)`는 에러가 난다. `\n`은 따옴표 안에서만 쓸 수 있으니 `print(a, b, sep="\n")`이나 `print(f"{a}\n{b}")`로 쓴다.
- [ ] `sep` = 값 사이의 구분자이며 기본값은 공백 `" "`이다.
- [ ] `sep`와 `end`에는 **문자열만** 넣을 수 있다. `sep=\n`은 에러가 나니 `sep="\n"`처럼 따옴표를 붙인다.
- [ ] `end` = print 끝에 붙는 문자이며 기본값은 `"\n"`이다.
- [ ] `f"...{변수}..."` → `{}` 안에 변수나 계산식을 넣으면 결과값이 출력된다. `{x:.2f}`는 소수 둘째 자리까지 출력한다.
- [ ] `%` 포맷은 `"%d, %s" % (a, b)`처럼 쓴다. 정수는 `%d`, 실수는 `%f`, 문자열은 `%s`, 문자는 `%c`이다.
- [ ] `format()`은 `"{0} {1}".format(a, b)`처럼 쓴다. 번호는 0부터 세고, `{이름}`에 `format(이름=변수)`로 연결할 수도 있다.
- [ ] 소수점 n째 자리까지 반올림 출력: `"%.nf" % a`, `"{0:.nf}".format(a)`, `f"{a:.nf}"`. 콜론 `:` 뒤에 형식을 쓴다.
- [ ] `round()`는 끝자리 0이 사라진다(`3.1`). 자리수를 맞춰야 할 때는 `.nf` 형식(`3.10`)을 쓴다.
