# Java — 코드트리 개념·풀이

코드트리로 Java를 공부하면서 몰랐던 개념과 문제 풀이를 정리합니다.
파트 구분은 [Trail_map.md](../Trail_map.md)의 Trail / Chapter 순서를 그대로 따릅니다.
파이썬으로 이미 푼 내용이 많아서, 필요한 곳에는 **파이썬과 비교**를 같이 적었습니다.
섹션마다 확인 문제가 있습니다 (해설은 접혀 있음).

문제 풀이는 Python과 같은 문제 폴더 이름(`trailN/문제이름/`)으로 미러합니다.
