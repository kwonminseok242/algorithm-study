## 1. `%`는 두 얼굴: 나머지 연산자 vs 문자열 서식

### 핵심 요약
- `%`는 **놓이는 위치**에 따라 뜻이 완전히 달라진다.
  - **숫자 사이**에 있으면 → **나머지(mod) 연산자**. `7 % 3` → `1`
  - **문자열 안**에 있으면 → **출력 형식 기호**. `"%.2f"` → 소수점 둘째 자리
- 서식으로 쓸 때의 정해진 모양은 `"%.2f" % 값` 이다. `%`가 문자열 **밖에 혼자** 있으면 문법 자체가 성립하지 않는다.
- 파이썬에서는 `%` 서식보다 **f-string이 더 쉽고 권장**된다. 굳이 `%`를 쓸 이유가 없다.

### 예시 코드

**❌ `%`를 문자열 밖에 쓴 경우**
```python
a, b = input().split()
print(%(int(a)+int(b))/(int(a)-int(b)), %.2f)
```
```
    print(%(int(a)+int(b))/(int(a)-int(b)), %.2f)
          ^
SyntaxError: invalid syntax
```
→ `%`는 혼자 설 수 없는 기호다. 파이썬이 "여기서 뭘 하라는 건지 모르겠다"고 멈춘 것.

**✅ 굳이 `%` 서식을 쓴다면 — 형식이 정해져 있다**
```python
a, b = map(int, input().split())
print("%.2f" % ((a + b) / (a - b)))
```
```
>> 10 3
1.86
```
- 왼쪽: **문자열** `"%.2f"` (따옴표 필수)
- 가운데: `%` (연결 기호)
- 오른쪽: 넣을 **값**

**✅ f-string이 훨씬 낫다 ⭐**
```python
a, b = map(int, input().split())
print(f"{(a + b) / (a - b):.2f}")
```

**참고 — 나머지 연산자로서의 `%`**
```python
print(7 % 3)    # 1  (7을 3으로 나눈 나머지)
print(10 % 2)   # 0  (나누어떨어짐 → 짝수 판별에 자주 쓰임)
print(25 % 24)  # 1  (시계 계산 등)
```

### 주의할 점
- `%.2f`의 `.2f`는 f-string의 `:.2f`와 **같은 의미**다. 붙는 기호만 `%` ↔ `:`로 다르다.
- `%` 서식과 f-string을 **섞어 쓰면 안 된다**. (ch2에서 본 `f"{}".format()` 금지와 같은 이유)
- 값이 2개 이상이면 `%`는 괄호로 묶어야 한다: `"%d %d" % (a, b)`
- 값이 1개여도 계산식이면 **괄호를 한 겹 더** 감싸는 게 안전하다: `% ((a+b)/(a-b))`

## 2. `map(int, ...)`으로 여러 값을 한 번에 정수로

### 핵심 요약
- `input().split()`의 결과는 **문자열들의 list**다. 계산하려면 하나씩 `int()`를 해야 했다.
- `map(int, 묶음)`은 **묶음의 모든 원소에 `int()`를 한꺼번에 적용**해 준다.
- `a, b = map(int, input().split())` 한 줄이면 입력 + 분리 + 정수 변환이 전부 끝난다.

### 예시 코드

**😵 매번 `int()`를 붙이면 — 길고 실수하기 쉽다**
```python
a, b = input().split()
print(f"{(int(a) + int(b)) / (int(a) - int(b)):.2f}")
```
→ `int()`가 4번이나 나온다. 하나라도 빠뜨리면 바로 에러.

**✅ `map`으로 입력받을 때 미리 바꿔두기 ⭐**
```python
a, b = map(int, input().split())
print(f"{(a + b) / (a - b):.2f}")
```
→ 이후로는 `a`, `b`를 그냥 숫자처럼 쓰면 된다.

**읽는 법**
```python
map(int, input().split())
#    ↑        ↑
#  적용할    대상 묶음
#   함수    (["10", "3"])
# → 10, 3
```

### 주의할 점
- `map`에 넘기는 건 `int()`가 아니라 **`int`** 다. 괄호를 붙이지 않는다.
  - `map(int, ...)` ✅ / `map(int(), ...)` ❌
- 실수로 받고 싶으면 `map(float, ...)`, 그대로 두려면 `map`을 쓰지 않으면 된다.
- 값이 여러 개일 땐 list로 감싼다: `arr = list(map(int, input().split()))`
- **출력만 할 값(앞의 0이 중요한 값)에는 쓰지 않는다.** `"09"` → `9`가 되어 형식이 깨진다. (ch2 11번과 같은 함정)

## 3. `/`는 항상 실수 + 반올림은 `:.2f`가 알아서 한다

### 핵심 요약
- 파이썬의 `/`는 **나누어떨어져도 결과가 항상 실수(float)** 다. `10 / 2` → `5` 가 아니라 `5.0`
- 소수점 자리수를 맞추라는 문제는 **따로 반올림 함수를 쓸 필요가 없다.** `:.2f`가 **반올림까지 해서** 잘라 준다.
- 즉 `round()`를 안 써도 된다. `:.2f` 하나면 끝.

### 예시 코드
```python
print(13 / 7)              # 1.8571428571428572
print(f"{13 / 7:.2f}")     # 1.86   ← 셋째 자리 7을 보고 반올림
print(f"{10 / 2:.2f}")     # 5.00   ← 자리수를 채워준다
```

**나눗셈 3형제 비교**
```python
print(13 / 7)    # 1.857...  나누기 (항상 float)
print(13 // 7)   # 1         몫만 (소수점 버림)
print(13 % 7)    # 6         나머지
```

### 주의할 점
- `round()`를 따로 쓰면 오히려 자리수가 깨질 수 있다. `round(5.0, 2)` → `5.0` (`5.00`이 아님)
- 나눗셈 문제는 **0으로 나누기**를 조심해야 한다. 이 문제는 제한 조건에 `b < a`가 있어서 `a - b`가 절대 0이 되지 않는다. → **제한 조건은 안전장치를 확인하는 용도로도 읽는다.**
- `//`는 소수점을 **버리는 것**이지 반올림이 아니다. `1.9 // 1` → `1.0`

## 4. 정답 정리 — 합과 차의 나눗셈

> 두 정수 a, b의 합 `(a+b)`를 차 `(a-b)`로 나눈 값을 반올림하여 소수점 둘째 자리까지 출력
> (제한: `1 ≤ b < a ≤ 1000`)

```python
a, b = map(int, input().split())
print(f"{(a + b) / (a - b):.2f}")
```
```
>> 10 3
1.86
```

**풀이 흐름**
1. 한 줄에 두 수가 공백으로 오니까 → `input().split()`
2. 계산해야 하니까 → `map(int, ...)`로 정수 변환
3. 소수점 둘째 자리까지 → f-string에 `:.2f`
4. **괄호 주의**: `a + b / a - b` 는 완전히 다른 식이다. 반드시 `(a + b) / (a - b)`

## 5. `avg()`는 없다 — 평균은 `sum()`과 `len()`으로 직접

### 핵심 요약
- 파이썬 기본 함수에 **`avg()`는 존재하지 않는다.** 쓰면 `NameError`가 난다.
- 있는 것들: `sum()`(합), `len()`(개수), `max()`(최댓값), `min()`(최솟값), `abs()`(절댓값)
- 그래서 **평균 = `sum(묶음) / len(묶음)`** 으로 직접 만든다. 공식이 아니라 그냥 "합 ÷ 개수"다.

### 예시 코드

**❌ 없는 함수를 부른 경우**
```python
a = int(input().split())
print(sum(a), avg(a))
```
```
----> 1 a = int(input().split())
TypeError: int() argument must be a string, a bytes-like object or a real number, not 'list'
```
→ 에러가 두 개 겹쳐 있다.
1. `int(list)` — `int()`는 값 **하나**만 바꾼다 (ch2 7번과 같은 함정)
2. `avg()` — 애초에 없는 이름이라 `NameError: name 'avg' is not defined`

**✅ 방법 ① 값이 2개뿐이면 그냥 직접 계산 ⭐**
```python
a, b = map(int, input().split())
print(f"{a + b} {(a + b) / 2:.1f}")
```
```
>> 2 5
7 3.5
```

**✅ 방법 ② `sum()` / `len()` 쓰기 (값이 많아지면 이쪽이 유리)**
```python
arr = list(map(int, input().split()))
print(f"{sum(arr)} {sum(arr) / len(arr):.1f}")
```
- `sum(arr)` → `7`
- `len(arr)` → `2`
- `7 / 2` → `3.5`

### 주의할 점
- **`sum()`은 list에 쓰는 함수다.** `sum(a, b)` ❌ / `sum([a, b])` ✅ / `a + b` ✅
- `sum()`에 넣으려면 원소가 **숫자**여야 한다. `sum(["2", "5"])`는 TypeError.
  → `list(map(int, ...))`로 먼저 숫자로 바꿔 둘 것.
- `map` 결과를 `sum()`에 바로 넣을 수는 있지만 **한 번 쓰면 사라진다.** 두 번 쓸 거면 `list()`로 감싸 두자.
- 모르는 함수는 만들어 내지 말고, **있는 함수 조합으로 표현**하는 습관을 들이자. (평균 = 합 ÷ 개수)

## 6. 정답 정리 — 합과 평균

> 두 정수 A, B를 입력받아 **합과 평균**을 공백을 사이에 두고 출력. 평균은 소수 첫째 자리까지.
> (제한: `1 ≤ A, B ≤ 100`)

```python
a, b = map(int, input().split())
print(f"{a + b} {(a + b) / 2:.1f}")
```
```
>> 2 5
7 3.5
```

**풀이 흐름**
1. 한 줄에 두 수가 공백으로 → `map(int, input().split())`
2. 합은 `a + b`, 평균은 `(a + b) / 2`
3. 평균은 소수 **첫째** 자리 → `:.1f` (둘째 자리는 `:.2f`)
4. 공백을 사이에 두고 출력 → f-string 안에 **직접 공백**을 넣거나 `print(a + b, (a + b) / 2)`처럼 쉼표를 써도 된다 (쉼표는 기본 구분자가 공백)

**`:.1f`를 꼭 써야 할까?**
```python
print(2 + 5, (2 + 5) / 2)   # 7 3.5   ← 이 예제는 우연히 맞다
print(2 + 4, (2 + 4) / 2)   # 6 3.0   ← 이것도 맞다 (/ 는 항상 float)
```
→ `/`가 항상 float이라 대부분 맞지만, **"소수 첫째 자리까지"라고 쓰여 있으면 `:.1f`로 명시**하는 게 안전하다.

## ✅ 한눈에 복습 체크리스트

- [ ] `%`는 **숫자 사이**면 나머지, **문자열 안**이면 출력 형식이다.
- [ ] `%`가 문자열 밖에 혼자 있으면 `SyntaxError`다.
- [ ] `%` 서식의 형태는 `"%.2f" % 값`. 계산식이면 `% ((...))`처럼 괄호를 한 겹 더 감싼다.
- [ ] `%.2f`와 `:.2f`는 같은 뜻. 파이썬에선 **f-string을 쓰자**.
- [ ] `map(int, input().split())`은 모든 조각을 한 번에 정수로 바꿔준다.
- [ ] `map`에는 `int()`가 아니라 **`int`** 를 넘긴다 (괄호 없이).
- [ ] 값이 여러 개면 `list(map(int, ...))`, 두세 개면 `a, b = map(int, ...)`.
- [ ] 앞의 0이 중요한 값(`09`)에는 `map(int, ...)`을 쓰면 안 된다.
- [ ] `/`는 나누어떨어져도 결과가 **항상 float**다. `10 / 2` → `5.0`
- [ ] 반올림은 `:.2f`가 알아서 해준다. `round()`는 필요 없다.
- [ ] `/` 나누기, `//` 몫, `%` 나머지 — 세 개를 구분하자.
- [ ] `(a + b) / (a - b)` — **괄호를 빠뜨리면 우선순위 때문에 완전히 다른 식**이 된다.
- [ ] 제한 조건(`b < a`)은 0으로 나누는 일이 없다는 **안전장치 확인용**으로도 읽는다.
- [ ] 파이썬에 **`avg()`는 없다.** 평균은 `sum(묶음) / len(묶음)`으로 직접 만든다.
- [ ] 있는 함수: `sum()`, `len()`, `max()`, `min()`, `abs()`
- [ ] `sum()`은 **list에 쓰는 함수**다. `sum(a, b)` ❌ / `sum([a, b])` ✅
- [ ] `sum()`에 넣을 원소는 숫자여야 한다. `list(map(int, ...))`로 먼저 변환.
- [ ] `int(list)`는 안 된다. `int()`는 값 하나만 바꾼다. (ch2 7번 재등장!)
- [ ] 소수 **첫째** 자리는 `:.1f`, **둘째** 자리는 `:.2f`.
- [ ] 공백 구분 출력은 f-string에 공백을 직접 넣거나 `print(x, y)` 쉼표를 쓴다.
- [ ] 모르는 함수는 지어내지 말고 **있는 함수 조합**으로 표현하자.
