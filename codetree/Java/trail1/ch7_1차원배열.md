## 1. 배열 선언하고 만들기 — `타입[] 이름 = new 타입[크기];`

### 핵심 요약
- 파이썬 list는 크기도 타입도 자유지만, Java 배열은 **타입 하나 + 크기 고정**이다.
- 기본 형태:
  ```java
  int[] arr = new int[5];
  // ↑타입[]  ↑이름   ↑"5칸짜리 int 배열을 새로 만들어라"
  ```
  - 왼쪽 `int[] arr` = **선언** ("arr는 int 배열이다")
  - 오른쪽 `new int[5]` = **생성** (실제로 5칸 메모리를 만든다)

| 하고 싶은 것 | Java | 파이썬 |
|---|---|---|
| 크기 n인 정수 배열 | `int[] arr = new int[n];` | `arr = [0] * n` |
| 문자열 배열 | `String[] arr = new String[n];` | `arr = [""] * n` (Java는 `null`로 채워짐) |
| 값을 바로 넣어서 만들기 | `int[] arr = {1, 2, 3};` | `arr = [1, 2, 3]` |
| 길이 | `arr.length` (괄호 없음!) | `len(arr)` |
| 값 넣기 / 읽기 | `arr[0] = 7;` / `arr[0]` | 같음 |

- `new`로 만들면 **기본값으로 자동 채워진다**: `int` → `0`, `double` → `0.0`, `boolean` → `false`, `String` → `null`.

### 예시 코드

**n개를 입력받아 배열에 저장하고 출력**
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] arr = new int[n];          // n칸 배열 생성

        for (int i = 0; i < n; i++)
            arr[i] = sc.nextInt();       // 한 칸씩 채우기

        for (int i = 0; i < arr.length; i++)
            System.out.print(arr[i] + " ");
    }
}
```
```
입력:
3
4 7 1
출력:
4 7 1
```

### 주의할 점
- ⚠️ **크기를 나중에 늘릴 수 없다.** `append()` 같은 건 없다. (크기가 변해야 하면 `ArrayList` 사용)
- ⚠️ 범위 밖 index 접근 → `ArrayIndexOutOfBoundsException`. 파이썬처럼 `arr[-1]`도 안 된다 → `arr[arr.length - 1]`.
- ⚠️ `arr.length`는 괄호가 없다. (문자열은 `s.length()` 괄호 있음 — 헷갈리기 쉬움)
- `System.out.println(arr)`은 내용이 아니라 `[I@1b6d3586` 같은 주소가 나온다. 내용을 보려면 for문 또는 `Arrays.toString(arr)`.

## 2. `main` 밖에 선언하는 `public static` / 상수 `final`

### 핵심 요약
- 코드트리 예시 코드는 배열을 `main` **밖**(클래스 안)에 이렇게 선언하는 경우가 많다:
  ```java
  public class Main {
      public static final int MAX_N = 6;               // 상수
      public static String[] arr = new String[MAX_N];  // 전역 배열

      public static void main(String[] args) { ... }
  }
  ```
- `static`: 클래스에 딱 하나 있는 변수 → `main`이나 다른 함수 어디서든 바로 쓸 수 있다. (파이썬의 **전역 변수** 느낌)
  - `main`이 `static`이라서, `main`에서 쓰려면 바깥 변수도 `static`이어야 한다.
- `final`: 한 번 정하면 **값을 못 바꾸는 상수**. 관례상 이름을 `MAX_N`처럼 대문자로 쓴다.
- 문제 조건의 최대 크기(`MAX_N`)로 배열을 넉넉히 미리 만들어 두고, 실제로는 입력받은 `n`칸만 쓰는 방식이다.

### 주의할 점
- `public`은 "어디서든 접근 가능"이라는 뜻. 코딩테스트에서는 생략해도 동작한다 (`static String[] arr = ...`).
- 함수 여러 개에서 같은 배열을 써야 할 때 이 방식이 편하다. `main` 안에서만 쓸 거면 1번처럼 `main` 안에서 `new int[n]`으로 만들어도 된다.

## 3. `Math.max` / `Math.min` — 둘 중 큰/작은 값

### 핵심 요약
- `Math.max(a, b)`: 둘 중 큰 값, `Math.min(a, b)`: 둘 중 작은 값. 파이썬 `max(a, b)` / `min(a, b)`.
- `import` 없이 바로 쓸 수 있다.

### 예시 코드
```java
int[] arr = {4, 7, 1};

int mx = arr[0];
for (int x : arr)
    mx = Math.max(mx, x);   // 지금까지 최댓값 vs 새 값

System.out.println(mx);    // 7
```

### 주의할 점
- ⚠️ 파이썬 `max(arr)`처럼 **배열을 통째로 넣을 수 없다.** 인자는 딱 두 개 → 반복문으로 하나씩 비교한다.
- 시작값은 `arr[0]`으로 하거나, 최댓값이면 `Integer.MIN_VALUE`, 최솟값이면 `Integer.MAX_VALUE`로 둔다.

## 4. `n + 1` 크기 배열로 1-based 쓰기 / 크기는 제한 조건으로

### 핵심 요약
```java
String[] words = new String[n + 1];   // n + 1칸 → 1번 ~ n번 칸 사용
for (int i = 1; i <= n; i++)
    words[i] = sc.next();
```
- **`n + 1` 크기 = 1-based 사용.** 문제의 번호와 인덱스가 일치해서 `-1` 변환이 필요 없다. 누적합에서 특히 유리하다.
- 배열 크기는 **예제가 아니라 제한 조건의 최댓값**으로 잡는다 (`static final int MAX_N = 100000;`).
- 접근은 **대괄호만** (`words[3]`). `.get()`은 없다 (`.get()`은 ArrayList·HashMap).

### 주의할 점
- 넘치면 `ArrayIndexOutOfBoundsException`.
- 1-based면 반복 조건은 `<=`.

### 🧩 확인 문제
**Q. 크기 `n + 1` 배열을 1번 칸부터 채우는 반복문의 조건은 `i < n`일까요, `i <= n`일까요?**

<details><summary>해설</summary>

**`i <= n`**이에요. `i < n`이면 마지막 n번째를 못 채워요. "1-based면 `<=`"로 묶어서 기억하세요.

</details>

## 5. `arr.length`는 "칸 수", 채운 개수가 아니다 / `size()`는 컬렉션 전용

### 핵심 요약
- 배열의 크기는 `new`로 만들 때 **고정**된다. 그래서 `arr.length`는 값을 몇 개 넣었든 **항상 만든 칸 수**가 나온다.
- ❌ **배열에는 `size()`가 없다.** `size()`는 `ArrayList`, `HashMap` 같은 **컬렉션**의 메서드다.
- 배열에 **실제로 채운 개수**는 Java가 알려주지 않는다 → **내가 변수(`n`, `cnt`)로 따로 세야 한다.**

| | 배열 `int[]` | ArrayList / HashMap |
|---|---|---|
| 크기 | 만들 때 고정 | 넣을수록 늘어남 |
| 길이 읽기 | `arr.length` (괄호 X) | `list.size()`, `map.size()` (괄호 O) |
| 의미 | **만든 칸 수** (빈 칸 포함) | **실제로 들어있는 개수** |
| 문자열 | `s.length()` (괄호 O) | |

### 예시 코드
```java
int[] arr = new int[100];     // MAX_N = 100칸
int n = sc.nextInt();         // 실제 입력은 3개
for (int i = 0; i < n; i++)
    arr[i] = sc.nextInt();

System.out.println(arr.length);   // 100  ← 채운 개수가 아님!
System.out.println(n);            // 3    ← 실제 개수는 내가 기억한 n
// arr.size();                    // ❌ 컴파일 오류

ArrayList<Integer> list = new ArrayList<>();
list.add(4); list.add(7); list.add(1);
System.out.println(list.size());  // 3  ← 컬렉션은 들어있는 개수
```

### 주의할 점
- ⚠️ `MAX_N`으로 넉넉하게 만든 배열을 `for (int i = 0; i < arr.length; i++)`로 돌면 **안 채운 빈 칸(0, null)까지** 돈다 → `i < n`으로 돌아야 한다.
  향상된 for `for (int x : arr)`도 빈 칸까지 전부 돈다.
- `new int[n]`처럼 딱 n칸으로 만들었을 때만 `arr.length == n`.
- 길이 3종 세트: 배열 `arr.length` / 문자열 `s.length()` / 컬렉션 `list.size()`.

### 🧩 확인 문제
**Q. `int[] arr = new int[100];`에 값을 5개만 넣었을 때 `arr.length`는?**

<details><summary>해설</summary>

**100**이에요. `length`는 만든 칸 수예요. 실제로 넣은 5개는 입력받을 때 쓴 `n`(또는 직접 센 `cnt`)으로 알아야 해요. 배열에는 `size()`가 없어요.

</details>
