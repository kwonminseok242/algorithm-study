## 1. `input()`은 항상 문자열로 받는다

### 핵심 요약
- 입력은 `input()` 함수로 받는다. 입력은 **항상 줄(line) 단위**로 읽어 온다.
- 이때 받아온 값은 **무조건 문자열(str) type**이다. 숫자를 입력해도 문자열 `"3"`이지 숫자 `3`이 아니다.
- 그래서 숫자로 계산하려면 **`int()`로 감싸서 정수형으로 바꿔줘야** 한다.

### 예시 코드

**❌ 바로 계산하면 에러**
```python
a = input()
print(a + 1)
```
```
>> 3

----> 3 print(a + 1)

TypeError: can only concatenate str (not "int") to str
```
→ "문자열 `a`에 숫자 `1`을 더할 수 없다"는 뜻이다.

**✅ 방법 ① 입력받은 뒤에 변환하기**
```python
a = input()
a = int(a)
print(a + 1)
```
```
>> 3
4
```

**✅ 방법 ② 입력받는 즉시 변환하기 (더 많이 쓰는 방식) ⭐**
```python
a = int(input())
print(a + 1)
```
```
>> 3
4
```

### 주의할 점
- `int(input())`은 **안쪽부터** 실행된다고 생각하면 쉽다. `input()`으로 `"3"`을 받고 → `int("3")`으로 `3`을 만들고 → `a`에 저장한다.
- `int()`로 바꿀 수 있는 건 **숫자로만 이루어진 문자열**이다. `int("abc")`처럼 쓰면 `ValueError`가 난다.
- 에러 메시지 `can only concatenate str (not "int") to str`는 **"문자열 + 숫자"를 했을 때** 나온다. 이 메시지를 보면 "아, `int()`를 안 씌웠구나"라고 바로 떠올리기.
- 반대로 두 값이 **둘 다 문자열**이면 에러 없이 그냥 이어 붙여진다. 이게 더 위험하다.
```python
a = input()          # 3 입력
print(a + "1")       # 31   ← 더하기가 아니라 이어붙이기!
```

## 2. `*` 연산: 문자열은 반복, 숫자는 곱하기

### 핵심 요약
- 겉보기에 똑같은 `a = a * 2`인데 **`a`의 type이 무엇이냐에 따라 결과가 완전히 달라진다.**

| `a`의 type | `a * 2`의 의미 | 3을 입력했을 때 결과 |
|---|---|---|
| 문자열 `str` | 문자열을 **2번 반복** | `33` |
| 정수 `int` | 숫자를 **2배로 곱함** | `6` |

### 예시 코드

**① `int()`를 안 씌운 경우 → 문자열 반복**
```python
a = input()      # "3"  (문자열!)
a = a * 2        # "3" + "3" = "33"
print(a)
```
```
>> 3
33
```

**② `int()`를 씌운 경우 → 숫자 곱하기**
```python
a = int(input())   # 3  (정수)
a = a * 2          # 3 × 2 = 6
print(a)
```
```
>> 3
6
```

### 왜 이런 차이가 생길까?
- 파이썬에서 `*`는 **양쪽 값의 type을 보고 하는 일을 정한다.**
  - `int * int` → 곱셈
  - `str * int` → 그 문자열을 int번 **이어 붙이기(반복)**
- 그러니까 `"3" * 2`는 `"3"`을 2번 이어 붙여서 `"33"`이 된다. 숫자 3을 2배 한 게 아니다.
- 코드 모양은 똑같아도 **`input()`에 `int()`를 씌웠는지 아닌지**가 결과를 바꾼다. → [1번 개념](#1-input은-항상-문자열로-받는다)과 이어지는 내용이다.

```python
print("abc" * 3)   # abcabcabc
print("-" * 10)    # ----------  (구분선 그을 때 유용!)
```

### 주의할 점
- `"3" * "2"`처럼 **문자열끼리 곱하면 에러**가 난다.
```
TypeError: can't multiply sequence by non-int of type 'str'
```
  → 반복 횟수는 반드시 정수여야 한다.
- `"3" * 2.0`도 에러다. `2.0`은 실수(float)라서 반복 횟수로 못 쓴다.
- 문제에서 **"입력받은 수의 2배를 출력하라"** 고 하면 `int(input())`을 꼭 써야 한다. 안 쓰면 에러도 안 나고 `33`이 조용히 출력되기 때문에 **틀린 걸 알아채기 어렵다.** ⚠️
- 결과가 이상할 땐 `print(type(a))`로 type을 찍어 보면 원인을 바로 알 수 있다.
```python
a = input()
print(type(a))   # <class 'str'>
a = int(a)
print(type(a))   # <class 'int'>
```

## 3. 형 변환 `float()`와 출력 형식 `:.2f`는 다른 것

### 틀린 코드
```python
N = input()
print(float(N:2.f))
```
```
  File "t1.py", line 2
    print(float(N:2.f))
                   ^
SyntaxError: invalid decimal literal
```

### 무엇이 잘못됐나 — 3가지가 섞여 있다

| # | 잘못된 부분 | 이유 |
|---|---|---|
| ① | `2.f` | 순서가 반대다. **`.2f`** 가 맞다 (점이 앞!). `2.f`는 숫자로 읽히다 말아서 `invalid decimal literal` 에러가 난다. |
| ② | `float(N : ...)` | **`:형식`은 함수 괄호 안에서 쓸 수 없다.** f-string이나 `format()`의 **중괄호 `{}` 안에서만** 쓸 수 있는 문법이다. |
| ③ | `float()`로 자리수를 맞추려 함 | `float()`는 **type을 바꾸는 함수**일 뿐, 출력 형식과는 아무 상관이 없다. |

### 핵심 요약
**"실수로 바꾸는 일"과 "소수점 자리수를 맞춰 출력하는 일"은 서로 다른 단계다.**

```
input()  →  "3.14159"   (문자열)
   ↓  float()           ← ① type 바꾸기 (형 변환)
          3.14159       (실수)
   ↓  f"{N:.2f}"        ← ② 보기 좋게 출력하기 (출력 형식)
          3.14
```

### 올바른 코드
```python
N = float(input())
print(f"{N:.2f}")
```
```
>> 3.14159
3.14
```

같은 결과를 내는 다른 방법 (→ ch1 7번 개념과 동일)
```python
print("%.2f" % N)          # % 포맷
print("{:.2f}".format(N))  # format()
print(f"{N:.2f}")          # f-string ⭐
```

### 주의할 점
- `float()`만 쓰면 **자리수가 그대로 다 나온다.** 잘라주는 기능이 없다.
```python
print(float("3.14159"))   # 3.14159  ← 2자리로 안 줄어든다
```
- 형 변환을 안 하고 문자열에 바로 `:.2f`를 쓰면 에러가 난다. **`float()`가 먼저**다.
```python
N = input()        # "3.14159" (문자열)
print(f"{N:.2f}")
# ValueError: Unknown format code 'f' for object of type 'str'
```
  → 이 에러 메시지의 뜻: "문자열한테 `f`(실수) 형식을 쓸 수 없다"
- 콜론 `:`은 **중괄호 `{}` 안에서만** 의미가 있다. `{무엇을 : 어떻게}` 구조를 기억하기.
- 정수는 `int()`, 실수는 `float()`로 바꾼다. 소수점이 있는 입력에 `int()`를 쓰면 `ValueError`가 난다.
```python
int("3.14")     # ❌ ValueError
float("3.14")   # ✅ 3.14
```

## 4. f-string 중괄호 `{}` 안에서 바로 변환하기

### 핵심 요약
- f-string의 중괄호 `{}` 안에는 **변수뿐 아니라 "식(계산)"도 넣을 수 있다.** `float(N)` 같은 형 변환도 식이므로 그대로 넣을 수 있다.
- 즉 변수에 따로 저장하지 않고 **출력하는 순간에 변환**할 수 있다.

```python
N = input()
print(f"{float(N):.2f}")
```
```
>> 3.14159
3.14
```

### `{}` 안의 구조를 다시 보기

```
 f"{  float(N)  :  .2f  }"
      ────────     ───
       ↑            ↑
      "무엇을"     "어떻게"
    (값 = 식 OK)   (출력 형식)
```

- **콜론 `:` 앞** = 출력할 값. 변수든 계산식이든 함수 호출이든 된다.
- **콜론 `:` 뒤** = 출력 형식. `.2f`처럼 형식만 쓴다.

→ 3번에서 틀렸던 `float(N:2.f)`와 비교해 보면, **`float()`와 `:.2f`의 위치가 반대**였던 것이다.

| | 코드 | 결과 |
|---|---|---|
| ❌ | `print(float(N:2.f))` | 함수 괄호 안에 `:` → SyntaxError |
| ✅ | `print(f"{float(N):.2f}")` | 중괄호 안, 콜론 앞에 `float(N)` → `3.14` |

### 두 가지 방법 비교

**방법 ① 입력받을 때 변환** (값을 계속 쓸 때 좋다)
```python
N = float(input())
print(f"{N:.2f}")
print(N * 2)          # 이후에도 숫자로 계속 쓸 수 있다
```

**방법 ② 출력할 때 변환** (한 번만 출력하면 될 때 간단하다)
```python
N = input()
print(f"{float(N):.2f}")
print(N * 2)          # ⚠️ N은 여전히 문자열! "3.141593.14159"가 나온다
```

> **정리:** 두 방법 다 맞지만, 입력값을 **계산에도 쓴다면 ①번**이 안전하다.
> ②번은 `N`이 문자열 그대로 남아 있다는 걸 꼭 기억하기.

### 활용 예시
```python
# 계산식도 그대로 넣을 수 있다
a, b = "10", "3"
print(f"{int(a) / int(b):.3f}")    # 3.333

# 정수 변환도 마찬가지
print(f"{int('7') * 2}")           # 14

# 형식을 쓰면 정수도 소수로 보여준다
print(f"{float('3'):.2f}")         # 3.00
```

### 주의할 점
- 편하다고 `{}` 안에 식을 너무 길게 넣으면 읽기 어려워진다. 복잡하면 위에서 변수로 먼저 계산하기.
- f-string 안의 따옴표는 **바깥과 다른 종류**를 쓰는 게 안전하다.
```python
print(f"{float('3.14'):.2f}")   # ✅ 바깥 " / 안쪽 '
```
- `{}` 안에 넣는 건 **식(값이 되는 것)** 이다. `a = 3` 같은 대입문은 넣을 수 없다.

## 5. 공백을 사이에 두고 입력받기: `split()`과 list

### 핵심 요약
- 파이썬의 입력은 **한 줄 단위로만** 받을 수 있다. 그런데 `13 17`처럼 한 줄에 두 개의 값이 들어오면?
- **`split()`** 은 문자열을 특정 기준으로 **잘라주는 함수**다. 그냥 쓰면 **공백 기준**으로 자른다.
- 잘린 조각들은 하나의 **list(리스트)** 로 묶여서 나온다.

```python
a = input()
print(a.split())
```
```
>> 13 17
['13', '17']
```

### list에서 원소 꺼내기 — 번호는 0부터

- list는 여러 원소를 들고 있는 **묶음**이다.
- 원소를 꺼낼 땐 대괄호 `[]`에 번호를 쓴다. 번호는 **0부터** 시작한다. (즉 `번째 수 - 1`)

```python
arr = [5, 6, 10]
print(f"First element is {arr[0]}")    # 5
print(f"Second element is {arr[1]}")   # 6
print(f"Third element is {arr[2]}")    # 10
```

```
 arr = [ 5 ,  6 ,  10 ]
         ↑    ↑    ↑
        [0]  [1]   [2]     ← 번호는 0부터!
       첫번째 두번째 세번째
```

### 두 정수를 입력받아 곱하기

**❌ 이렇게 하면 에러**
```python
a = input()
arr = a.split()
n = arr[0]
m = arr[1]

print(n)
print(m)
print(n * m)
```
```
>> 13 17

13
17
TypeError: can't multiply sequence by non-int of type 'str'
```

→ `split()`으로 잘라도 **조각 하나하나는 여전히 문자열**이다. `arr`은 `[13, 17]`이 아니라 `['13', '17']`이다.
→ 문자열끼리 곱할 수 없으니 에러가 난다. ([2번 개념](#2--연산-문자열은-반복-숫자는-곱하기)과 같은 이유)

**✅ `int()`로 바꿔주기**
```python
a = input()
arr = a.split()
n = int(arr[0])
m = int(arr[1])

print(n)
print(m)
print(n * m)
```
```
>> 13 17
13
17
221
```

### Side Note — `input()`과 `split()`을 한 줄로 잇기

```python
arr = input().split()
n = int(arr[0])
m = int(arr[1])

print(n * m)
```

- `input().split()`은 "입력을 받고 → 그 결과를 바로 자른다"는 뜻이다. **점 `.`으로 이어서** 쓸 수 있다.
- `a`라는 변수를 따로 두지 않아도 되니 더 짧고, 실제로 이 방식을 많이 쓴다. ⭐

### 주의할 점
- `split()`의 결과는 **항상 문자열들의 list**다. 숫자로 쓰려면 원소마다 `int()`를 씌워야 한다.
- 번호는 **0부터**다. 두 번째 값은 `arr[1]`이다. `arr[2]`처럼 없는 번호를 쓰면 에러가 난다.
```
IndexError: list index out of range
```
- `split()`은 **괄호를 비워두는 게** 가장 안전하다. 공백이 여러 칸이거나 앞뒤에 공백이 있어도 알아서 깔끔하게 잘라준다.
```python
"   13   17  ".split()      # ['13', '17']   ✅
"13  17".split(" ")         # ['13', '', '17']  ⚠️ 빈 조각이 생김
```
- 공백이 아닌 다른 기준으로 자르려면 괄호 안에 넣는다.
```python
"13,17".split(",")          # ['13', '17']
```
- `print(n)`, `print(m)`까지는 잘 나오고 **마지막 줄에서만 에러가 난다.** 에러가 났다고 코드 전체가 틀린 게 아니라, **에러 난 줄**을 봐야 한다.

## 6. 여러 변수에 한 번에 담기 + 두 수 곱하기 정답 정리

### 새로 나온 문법: 한 번에 여러 변수에 담기 (언패킹)

```python
a, b = input().split()
```
- `split()`이 만든 list의 원소를 **왼쪽 변수들에 순서대로 하나씩** 넣어준다.
- `arr[0]`, `arr[1]`로 꺼내는 과정을 생략할 수 있어서 훨씬 짧다.

```
 input().split()  →  ['13', '17']
                        │      │
        a,     b    =   ▼      ▼
        a='13'        b='17'
```

### ❌ 안 되는 코드 2가지 — 원인은 똑같다

```python
a, b = input().split()
print(a * b)
```
```python
arr = input().split()
print(arr[0] * arr[1])
```
둘 다 `13 17`을 입력하면:
```
TypeError: can't multiply sequence by non-int of type 'str'
```

**원인: `split()`의 결과는 문자열이다.**
- 변수에 예쁘게 나눠 담든(`a, b`), 번호로 꺼내든(`arr[0]`) **담는 방법만 다를 뿐 내용물은 그대로 문자열**이다.
- `a`는 `13`이 아니라 `'13'`이고, `b`는 `'17'`이다. 문자열끼리는 곱할 수 없다.
- `int()`를 어디에 씌우느냐가 빠진 것이지, 언패킹이나 대괄호 문법이 틀린 게 아니다.

> 💡 **기억하기:** `split()`은 **자르기만** 한다. **숫자로 바꿔주지는 않는다.**

### ✅ 정답 코드 — 두 정수를 입력받아 곱하기

**방법 ① 꺼내면서 바로 변환 (한 줄)**
```python
arr = input().split()
print(int(arr[0]) * int(arr[1]))
```

**방법 ② 변수에 담아두고 계산 (읽기 편함) ⭐**
```python
arr = input().split()

a = int(arr[0])
b = int(arr[1])

print(a * b)
```

**방법 ③ 언패킹 + 각각 변환**
```python
a, b = input().split()

a = int(a)
b = int(b)

print(a * b)
```

모두 같은 결과:
```
>> 13 17
221
```

> 셋 다 정답이다. **방법 ②가 가장 읽기 쉽고 실수도 적다.**
> 값을 여러 번 쓸 거라면 변수에 **숫자로 저장해 두는 편**이 안전하다.

### 주의할 점
- 언패킹은 **변수 개수와 입력 개수가 정확히 맞아야** 한다.
```python
a, b = "13 17 19".split()   # ❌ ValueError: too many values to unpack (expected 2, got 3)
a, b = "13".split()         # ❌ ValueError: not enough values to unpack (expected 2, got 1)
```
  → "2개를 기대했는데 3개가 왔다"는 뜻이다. **입력 개수를 다시 확인하기.**
- `int()`를 씌우는 위치를 헷갈리지 않기. **`int(arr[0])`** 이다.
  - `int(arr)[0]` ❌ — list 전체를 int로 바꿀 수 없다.
  - `arr[int(0)]` ❌ — 번호가 아니라 **원소**를 바꿔야 한다.
- 변수 이름은 문제에서 시키는 대로(`a`, `b` / `n`, `m`) 쓰면 헷갈리지 않는다.

## 7. 괄호 빠뜨림 `split` vs `split()` / list는 `int()`로 못 바꾼다

### 틀린 코드
```python
arr = int(input().split)
print(arr[0], arr[1], arr[0] + arr[1])
```
```
TypeError: int() argument must be a string, a bytes-like object or a real number,
           not 'builtin_function_or_method'
```

### 잘못된 점 2가지

| # | 잘못된 부분 | 이유 |
|---|---|---|
| ① | `split` — **괄호 `()` 없음** | 함수를 **실행하지 않고, 함수 자체**를 가리킨 것이 된다. |
| ② | `int( ... )` 로 통째로 감쌈 | `int()`는 **값 하나**만 바꾼다. **list 전체**는 못 바꾼다. |

### ① 괄호가 없으면 "실행"이 아니다 ⭐

```python
s = "13 17"

print(s.split)     # <built-in method split of str object at 0x...>  ← 함수 그 자체
print(s.split())   # ['13', '17']                                    ← 실행한 결과
```

- **괄호 `()` = "실행해라"** 라는 뜻이다. 괄호가 없으면 "이런 함수가 있다"는 사실만 가리킨다.
- `input()`에는 괄호를 붙였으면서 `split`에는 안 붙인 상황. **함수 뒤에는 항상 괄호**를 붙여야 한다.
- 에러 메시지의 `builtin_function_or_method`가 바로 **"너 지금 함수 자체를 넘겼어"** 라는 신호다. 이 단어가 보이면 **괄호를 빠뜨렸는지** 먼저 확인하기.

```python
arr = input().split      # ❌ arr에 함수가 담김
arr[0]                   # TypeError: 'builtin_function_or_method' object is not subscriptable
```

### ② `int()`는 list를 못 바꾼다

괄호를 제대로 붙여도 이번엔 다른 에러가 난다.
```python
arr = int(input().split())
# TypeError: int() argument must be a string, a bytes-like object or a real number, not 'list'
```

```
   int( ['13', '17'] )     ❌  묶음 전체를 숫자 하나로? → 불가능
   int('13'), int('17')    ✅  원소 하나하나를 바꾼다
```

- `int()`가 받을 수 있는 건 **문자열이나 숫자 하나**다. 여러 개가 든 묶음(list)은 못 받는다.
- 그래서 `int()`는 **꺼낸 다음에, 원소마다** 씌워야 한다. → [6번 개념](#6-여러-변수에-한-번에-담기--두-수-곱하기-정답-정리)과 같은 이야기

### ✅ 고친 코드

```python
arr = input().split()

a = int(arr[0])
b = int(arr[1])

print(a, b, a + b)
```
```
>> 13 17
13 17 30
```

한 줄로 쓰면:
```python
arr = input().split()
print(int(arr[0]), int(arr[1]), int(arr[0]) + int(arr[1]))
```

### 에러 메시지로 원인 찾기 🔍

| 에러 메시지에 보이는 단어 | 원인 |
|---|---|
| `builtin_function_or_method` | 함수 뒤에 **괄호 `()`를 빠뜨렸다** |
| `not 'list'` | **묶음 전체**를 `int()`로 바꾸려 했다 |
| `not 'str'` | 문자열을 숫자처럼 쓰려 했다 (`int()` 필요) |

### 주의할 점
- `print(a, b, a + b)`처럼 쉼표로 여러 값을 쓰면 **공백으로 구분되어** 한 줄에 출력된다. (ch1의 `sep` 개념)
- `int(arr)[0]`도 틀린다. **괄호 위치**가 아니라 **씌우는 대상**이 중요하다. → `int(arr[0])`
- 참고: 나중에 `map`을 배우면 원소 전체를 한 번에 바꿀 수 있다. (지금은 몰라도 된다)
```python
a, b = map(int, input().split())    # 두 값을 한 번에 정수로!
print(a, b, a + b)
```

## 8. 여러 값을 줄바꿔 출력하기 — `end`가 아니라 `sep`

여러 개를 입력받아 **각각 다른 줄에, 소수는 둘째 자리까지** 출력하는 상황이다.
(입력: `hello` / `3.5` / `2.60`)

### ❌ 생각대로 안 되는 코드
```python
c = input()
a = float(input())
b = float(input())

print(c, a, b, end="\n")
```
```
hello 3.5 2.6
```
- 줄도 안 바뀌고, 소수점 자리수도 안 맞는다.

### 왜 이렇게 나올까 — 2가지 이유

**① `end`는 값 사이가 아니라 "print가 끝난 뒤"에 붙는다**

```
 print( c , a , b )
         └─┬─┘ └┬┘   ← 값 사이 = sep  (기본값 " " 공백)
          sep  sep
                    ↑
                    └ 전부 끝난 뒤 맨 끝 = end  (기본값 "\n" 줄바꿈)
```

- `end="\n"`은 **원래 기본값**이다. 적어도 안 적어도 결과가 똑같다. → 아무 일도 하지 않은 셈
- 값 **사이**를 바꾸고 싶은 거였으니 써야 할 건 **`sep`** 이다. (ch1 4·5번 개념)

**② `float`은 그냥 출력하면 입력한 모양 그대로 나오지 않는다**

```python
print(float("3.50"))   # 3.5    ← 뒤의 0이 사라짐
print(float("7"))      # 7.0    ← 없던 .0이 붙음
```
- 실수는 **파이썬이 정한 방식대로** 출력된다. 자리수를 맞추려면 **`:.2f` 형식**을 직접 써야 한다. ([3번 개념](#3-형-변환-float와-출력-형식-2f는-다른-것))

### ✅ 해결 방법 2가지

**방법 ① `sep="\n"` 쓰기** — 줄바꿈은 되지만 **자리수는 못 맞춘다**
```python
print(c, a, b, sep="\n")
```
```
hello
3.5
2.6
```

**방법 ② f-string** — 줄바꿈과 자리수를 **한 번에** 해결 ⭐
```python
print(f"{c}\n{a:.2f}\n{b:.2f}")
```
```
hello
3.50
2.60
```

> **정리:** 줄만 바꾸면 될 땐 `sep="\n"`, **출력 형식(소수점 자리수)까지 필요하면 f-string**이 답이다.
> 코딩테스트에서는 자리수를 지정하는 문제가 많으니 **f-string을 기본으로** 쓰는 습관을 들이면 편하다.

### 같은 결과를 내는 다른 방법
```python
# print를 여러 번 쓰기
print(c)
print(f"{a:.2f}")
print(f"{b:.2f}")

# sep에 형식 맞춘 문자열을 넘기기
print(c, f"{a:.2f}", f"{b:.2f}", sep="\n")
```

### 주의할 점
- `sep`, `end`에는 **문자열만** 넣을 수 있다. `sep=\n` ❌ → `sep="\n"` ✅
- `end=""`로 하면 줄바꿈이 사라져서 **다음 출력이 옆에 붙는다.** 일부러 이어 붙일 때만 쓴다.
- 입력을 3줄로 받을 땐 `input()`을 **3번** 부른다. 한 줄에 공백으로 들어오는 경우(`split()`)와 헷갈리지 않기.
```python
# 줄마다 따로 들어올 때        # 한 줄에 같이 들어올 때
a = float(input())            a, b = input().split()
b = float(input())            a, b = float(a), float(b)
```
- 실수 계산에는 아주 작은 오차가 있다. 그래서 형식 지정 없이 출력하면 이상하게 보일 수 있다.
```python
print(0.1 + 0.2)          # 0.30000000000000004  😵
print(f"{0.1+0.2:.2f}")   # 0.30  ✅
```

## 9. 문자열은 변환이 필요 없다 + 두 값 맞바꾸기(swap)

### 문제: 문자열 순서 바꾸기
> 문자열 `S`와 `T`를 입력받아 순서를 바꾸어 출력하기
> 입력: 첫 줄에 `S`, 둘째 줄에 `T` / 출력: 첫 줄에 `T`, 둘째 줄에 `S`

### ✅ 내가 푼 코드 (정답)
```python
s = input()
t = input()
print(t)
print(s)
```
```
>> abc
>> xyz
xyz
abc
```

### 여기서 기억할 점

**① 문자열은 `int()`, `float()`이 필요 없다**
- `input()`은 원래 문자열을 준다. 문자열 문제는 **받은 그대로 쓰면 된다.**
- 지금까지 변환이 필요했던 건 **계산을 해야 했기** 때문이다. 계산이 없으면 변환도 없다.

| 문제 유형 | 받는 법 |
|---|---|
| 숫자를 계산해야 함 | `int(input())`, `float(input())` |
| 문자열을 그대로 다룸 | `input()` ⭐ |

**② 값을 바꾸는 게 아니라 "출력 순서"만 바꾸면 된다**
- `s`와 `t`의 내용을 실제로 맞바꿀 필요가 없다. `print`를 쓰는 **순서만** 바꾸면 끝이다.
- 문제가 "순서를 바꾸라"고 해서 변수까지 바꿔야 하는 건 아니다. **가장 단순한 방법을 먼저 떠올리기.**

**③ 참고: 파이썬의 맞바꾸기(swap) 문법**

값 자체를 진짜로 맞바꿔야 할 때는 이렇게 쓴다. (이 문제에는 필요 없지만 나중에 자주 쓴다)
```python
s, t = t, s      # 한 줄로 교환 끝!
print(s, t)      # xyz abc
```
- 다른 언어에서는 임시 변수가 필요한데, 파이썬은 **한 줄로** 된다. ([6번 언패킹](#6-여러-변수에-한-번에-담기--두-수-곱하기-정답-정리)과 같은 원리)

### 주의할 점
- 입력이 **2줄**이므로 `input()`을 **2번** 부른다. `split()`을 쓰는 경우가 아니다.
- `print(t)` / `print(s)` 두 줄로 쓰면 줄바꿈은 자동이다. 한 줄로 쓰려면 `print(t, s, sep="\n")`이나 `print(f"{t}\n{s}")`. ([8번 개념](#8-여러-값을-줄바꿔-출력하기--end가-아니라-sep))
- 출력 순서를 반대로 쓰지 않았는지 **문제의 출력 조건을 다시 확인**하는 습관 들이기. (T가 먼저!)

## 10. 특정 문자를 기준으로 자르기: `split("문자")`

### 핵심 요약
- `split()`은 **기본이 공백 기준**이다.
- 공백이 아닌 다른 문자(`:`, `,`, `-` 등)로 자르고 싶으면 **괄호 안에 그 문자를 적어주면** 된다.

```python
a = input()
print(a.split(":"))
```
```
>> 50:60
['50', '60']
```

```
  "50:60"  --split(":")-->  ['50', '60']
       ↑
   이 문자를 기준으로 자르고, 기준 문자 자체는 사라진다
```

### 자주 쓰는 구분자

```python
"50:60".split(":")        # ['50', '60']        시각 (시:분)
"2026-09-20".split("-")   # ['2026', '09', '20']  날짜
"a,b,c".split(",")        # ['a', 'b', 'c']     쉼표 구분
```

### 실제 문제에 쓰기
`50:60`처럼 `:`를 사이에 두고 두 수를 입력받아 더하기
```python
a, b = input().split(":")

a = int(a)
b = int(b)

print(a + b)
```
```
>> 50:60
110
```
→ 구분자만 바뀌었을 뿐, **그 뒤는 [5·6번 개념](#5-공백을-사이에-두고-입력받기-split과-list)과 똑같다.**
   자른 조각은 여전히 **문자열**이므로 계산하려면 `int()`가 필요하다.

### 주의할 점
- 기준으로 쓴 문자는 **결과에서 사라진다.** `['50', ':', '60']`이 아니다.
- 구분자도 **문자열**이라 따옴표가 필요하다. `split(:)` ❌ → `split(":")` ✅
- **빈 괄호 `split()`과 `split(" ")`는 다르다.**

| 코드 | 기준 | 공백이 여러 칸일 때 |
|---|---|---|
| `split()` | 공백 (알아서 처리) | `['13', '17']` ✅ |
| `split(" ")` | 정확히 공백 1칸 | `['13', '', '17']` ⚠️ |

  → 공백 기준일 땐 **빈 괄호**가 안전하다. 구분자가 정해져 있을 때만 괄호 안에 적는다.
- 구분자가 **연달아 나오면 빈 조각**이 생긴다.
```python
"50::60".split(":")     # ['50', '', '60']
```
- 문자열에 **구분자가 없으면** 자르지 않고 통째로 하나가 된다. 에러가 나지 않으니 더 조심해야 한다.
```python
"50:60".split()         # ['50:60']   ← 공백이 없어서 안 잘림
```
  → 이 상태로 언패킹하면 `ValueError: not enough values to unpack`이 난다. **문제의 입력 형식을 먼저 확인하기.**
- 구분자가 여러 개면 조각도 그만큼 늘어난다. **변수 개수를 맞춰야** 한다.
```python
a, b = "50:60:70".split(":")   # ❌ too many values to unpack (expected 2, got 3)
```

## 11. 필요한 것만 변환하기 + 자리수 채우기 `:02d`

### 문제: 1시간 뒤 시간 출력
> `h:m` 형태로 시간을 입력받아 1시간 뒤의 시간을 같은 형태로 출력
> 제한: `1 ≤ h ≤ 22`, `0 ≤ m < 60`

### ✅ 내가 푼 코드 (정답)
```python
arr = input().split(":")
print(f"{int(arr[0])+1}:{arr[1]}")
```
```
>> 12:05
13:05
```

### 더 나은 방법 — 언패킹으로 이름 붙이기 ⭐
```python
h, m = input().split(":")
print(f"{int(h)+1}:{m}")
```
- `arr[0]`, `arr[1]`보다 **`h`, `m`이 무엇인지 바로 보인다.**
- 번호를 헷갈릴 일도 없다. 값이 2~3개면 **언패킹이 거의 항상 더 낫다.** ([6번 개념](#6-여러-변수에-한-번에-담기--두-수-곱하기-정답-정리))

시간을 먼저 계산해 두면 더 읽기 쉽다.
```python
h, m = input().split(":")
h = int(h) + 1
print(f"{h}:{m}")
```

### 💡 잘한 점: `m`은 일부러 문자열로 둔 것

**`m`에도 `int()`를 씌웠다면 오답이 된다.**
```python
print(f"{int(arr[0])+1}:{int(arr[1])}")   # 12:05 → 13:5  ❌
```
- `int("05")`는 `5`가 되어 **앞의 `0`이 사라진다.**
- 출력 형식이 입력과 같아야 하는데 `13:05`가 아니라 `13:5`가 되어 틀린다.

> **규칙:** **계산에 쓰는 값만** 숫자로 바꾼다.
> 그대로 출력만 할 값은 **문자열로 두는 게 안전하다.** (앞의 0이 보존된다)

### 숫자로 바꿨다면 — 자리수 채우기 `:02d`

만약 `m`을 숫자로 계산해야 했다면, 출력할 때 **0을 채워주는 형식**을 쓴다.
```python
print(f"{5:02d}")     # 05
print(f"{23:02d}")    # 23
```
```
 f"{ m : 02d }"
       │  ││└ d = 정수(decimal)
       │  │└─ 2 = 전체 2칸
       │  └── 0 = 빈 칸을 0으로 채움
       └───── 출력할 값
```
- `:.2f`가 **소수점 자리수**를 맞추는 형식이라면, `:02d`는 **정수의 자리수**를 맞추는 형식이다. ([3번 개념](#3-형-변환-float와-출력-형식-2f는-다른-것))

### 주의할 점
- 이 문제는 제한이 `h ≤ 22`라서 **1을 더해도 23을 넘지 않는다.** 그래서 그냥 더하면 된다.
- 만약 `h ≤ 23`이었다면 `24 → 0`으로 되돌려야 한다. (참고)
```python
h = (int(h) + 1) % 24      # 23 + 1 → 0
print(f"{h:02d}:{m}")
```
  → 문제의 **제한 조건을 꼭 읽어야** 이런 처리가 필요한지 알 수 있다. ⭐
- 출력 형식에 `:`을 빠뜨리지 않기. f-string 안의 `:`은 **중괄호 `{}` 밖에 있으면** 그냥 글자다.
```python
f"{h}:{m}"     # ✅ 중괄호 밖의 : → 글자 그대로 출력
f"{h:m}"       # ❌ 중괄호 안의 : → 출력 형식으로 해석됨
```

## 12. f-string과 `format()`을 섞어 쓰면 안 된다 + 순서 바꿔 출력하기

### 문제: 날짜 변경하여 출력
> `mm-dd-yyyy` 형태의 날짜를 입력받아 **`yyyy.mm.dd`** 형식으로 출력
> 예: `09-20-2026` → `2026.09.20`

### 틀린 코드
```python
time = input().split("-")
print(f"{}.{}.{}".format(time))
```
```
    print(f"{}.{}.{}".format(time))
             ^
SyntaxError: f-string: valid expression required before '}'
```

### 잘못된 점 3가지

| # | 잘못된 부분 | 이유 |
|---|---|---|
| ① | `f"..."`와 `.format()`을 **같이** 씀 | 둘은 **서로 다른 방법**이다. 하나만 골라 써야 한다. |
| ② | `{}`가 **비어 있음** | f-string의 `{}` 안에는 **반드시 값**이 들어가야 한다. |
| ③ | 순서를 안 바꿈 | `mm-dd-yyyy` → `yyyy.mm.dd`니까 **자리를 옮겨야** 한다. |

### ① f-string과 `format()`은 둘 중 하나만

| 방법 | 값을 어디에 쓰나 |
|---|---|
| **f-string** | `f"{값}"` — **중괄호 안에 직접** |
| **`format()`** | `"{}".format(값)` — **괄호 안에 따로** (중괄호는 비움) |

```python
f"{a}.{b}"              # ✅ f-string
"{}.{}".format(a, b)    # ✅ format
f"{}.{}".format(a, b)   # ❌ 섞어 쓴 것 → SyntaxError
```
- `f`를 붙였으면 `{}` 안에 값을 넣고, `format()`을 쓸 거면 `f`를 떼야 한다.
- 에러 메시지 `valid expression required before '}'` = **"중괄호 안이 비었다"** 는 뜻이다.

### ② `format()`에 list를 통째로 넘기면 안 된다

`f`를 떼도 이번엔 다른 에러가 난다.
```python
print("{}.{}.{}".format(time))
# IndexError: Replacement index 1 out of range for positional args tuple
```
- `time`은 `['09', '20', '2026']` **묶음 하나**다. `{}`는 3개인데 넘긴 값은 1개라서 에러가 난다.
- 원소를 하나씩 넘겨야 한다. ([7번의 `int(arr)` ❌](#7-괄호-빠뜨림-split-vs-split--list는-int로-못-바꾼다)와 같은 실수다)

### ③ 순서 바꾸기 — 이 문제의 핵심

```
 입력  09 - 20 - 2026        출력  2026 . 09 . 20
       mm   dd   yyyy              yyyy   mm   dd
       [0]  [1]  [2]                [2]  [0]  [1]
                    └──────┐    ┌────┘
                     자리를 옮긴다!
```

### ✅ 정답 코드

**방법 ① 언패킹 + f-string (가장 읽기 쉬움)** ⭐
```python
mm, dd, yyyy = input().split("-")
print(f"{yyyy}.{mm}.{dd}")
```

**방법 ② 번호로 꺼내기**
```python
time = input().split("-")
print(f"{time[2]}.{time[0]}.{time[1]}")
```

**방법 ③ `format()`만 쓰기**
```python
time = input().split("-")
print("{2}.{0}.{1}".format(*time))
```

모두 같은 결과:
```
>> 09-20-2026
2026.09.20
```

> 방법 ①이 가장 좋다. **`mm`, `dd`, `yyyy`라고 이름을 붙여두면 순서를 바꿀 때 헷갈리지 않는다.**
> 번호(`[0]`, `[2]`)로만 다루면 자리를 옮기다 실수하기 쉽다.

### 주의할 점
- 이 문제는 **숫자로 바꿀 필요가 전혀 없다.** 자리만 옮겨 출력하는 것이라 문자열 그대로가 맞다.
  → `int()`를 씌우면 `09`가 `9`가 되어 오답이 된다! ([11번 개념](#11-필요한-것만-변환하기--자리수-채우기-02d))
- 입력은 `-`로 자르고, 출력은 `.`으로 잇는다. **구분자가 다르다**는 점을 놓치지 않기.
- `format(*time)`의 `*`는 "묶음을 풀어서 하나씩 넘겨라"라는 뜻이다. (지금은 방법 ①을 쓰면 몰라도 된다)
- 에러가 두 번 연달아 날 수 있다. **하나 고치면 다음 에러가 보이는 건 정상**이다. 하나씩 차근차근 고치면 된다.

## 🔁 한눈에 복습 (체크리스트)

- [ ] `input()`은 줄 단위로 입력을 받고, 결과는 **항상 문자열(str)** 이다.
- [ ] 문자열 + 숫자는 `TypeError: can only concatenate str (not "int") to str` 에러가 난다.
- [ ] 숫자로 쓰려면 `a = int(a)` 또는 `a = int(input())`으로 정수형 변환을 해야 한다.
- [ ] 숫자로만 이루어진 문자열이 아니면 `int()`에서 `ValueError`가 난다.
- [ ] `*`는 type에 따라 하는 일이 다르다. `int * int`는 곱셈, `str * int`는 문자열 반복이다.
- [ ] 3을 입력했을 때 `input()`이면 `a*2`는 `33`, `int(input())`이면 `6`이다.
- [ ] 문자열끼리 곱하면 `TypeError: can't multiply sequence by non-int of type 'str'` 에러가 난다.
- [ ] `"-" * 10`처럼 구분선을 그을 때 문자열 반복을 활용할 수 있다.
- [ ] 결과가 이상하면 `print(type(a))`로 type을 확인해 본다.
- [ ] 형식은 `.2f`다. `2.f`처럼 점을 뒤에 쓰면 `SyntaxError: invalid decimal literal`이 난다.
- [ ] `:형식`은 f-string이나 `format()`의 중괄호 `{}` 안에서만 쓸 수 있다. 함수 괄호 안에는 못 쓴다.
- [ ] `float()`는 type을 바꿀 뿐 자리수를 잘라주지 않는다. 출력 형식은 `:.2f`가 담당한다.
- [ ] 소수점 출력의 정석: `N = float(input())` → `print(f"{N:.2f}")` (형 변환 먼저, 출력 형식 나중)
- [ ] 문자열에 바로 `:.2f`를 쓰면 `ValueError: Unknown format code 'f' for object of type 'str'`가 난다.
- [ ] 소수점이 있는 입력에 `int()`를 쓰면 `ValueError`가 난다. `float()`를 써야 한다.
- [ ] f-string의 `{}` 안에는 변수뿐 아니라 `float(N)`, `int(a)/int(b)` 같은 **식**도 넣을 수 있다.
- [ ] `f"{float(N):.2f}"` → 콜론 앞이 "무엇을"(값), 뒤가 "어떻게"(형식). `float(N:2.f)`는 위치가 반대라 틀린다.
- [ ] 출력할 때만 변환하면 원래 변수는 **문자열 그대로** 남는다. 계산에도 쓸 거면 `N = float(input())`로 받자.
- [ ] 입력은 한 줄 단위로만 받는다. 한 줄에 여러 값이 있으면 `split()`으로 자른다.
- [ ] `split()`은 기본이 공백 기준이고, 결과는 **문자열들의 list**다. → `['13', '17']`
- [ ] list의 원소는 `arr[0]`, `arr[1]`처럼 꺼내고 **번호는 0부터** 시작한다.
- [ ] `split()` 결과끼리 곱하면 `TypeError: can't multiply sequence by non-int of type 'str'`. `int(arr[0])`로 변환해야 한다.
- [ ] `arr = input().split()`처럼 점으로 이어서 한 줄로 쓸 수 있다.
- [ ] 없는 번호를 꺼내면 `IndexError: list index out of range`가 난다.
- [ ] `split(" ")`보다 `split()`이 안전하다. 공백이 여러 칸이어도 빈 조각이 안 생긴다.
- [ ] `a, b = input().split()`으로 두 값을 한 번에 담을 수 있다(언패킹).
- [ ] 언패킹을 해도, `arr[0]`으로 꺼내도 **내용물은 여전히 문자열**이다. `split()`은 자르기만 한다.
- [ ] 두 수 곱하기 정답: `arr = input().split()` → `a = int(arr[0])`, `b = int(arr[1])` → `print(a * b)`
- [ ] `int()`는 원소에 씌운다. `int(arr[0])` ✅ / `int(arr)[0]` ❌
- [ ] 변수 개수와 입력 개수가 다르면 `ValueError: too many(not enough) values to unpack`이 난다.
- [ ] 함수는 **괄호 `()`를 붙여야 실행**된다. `split`은 함수 자체, `split()`이 실행 결과다.
- [ ] 에러에 `builtin_function_or_method`가 보이면 **괄호를 빠뜨린 것**이다.
- [ ] `int()`는 값 하나만 바꾼다. `int(arr)` ❌ / `int(arr[0])` ✅
- [ ] 에러에 `not 'list'`가 보이면 묶음 전체를 변환하려 한 것이다.
- [ ] `print(a, b, a + b)`는 쉼표로 여러 값을 한 줄에 공백 구분해서 출력한다.
- [ ] `sep` = 값 **사이**, `end` = print가 **끝난 뒤**. 줄바꿔 출력하려면 `sep="\n"`이다.
- [ ] `end="\n"`은 기본값이라 적어도 아무 변화가 없다.
- [ ] `float`을 그냥 출력하면 `3.50`→`3.5`, `7`→`7.0`처럼 모양이 바뀐다. 자리수는 `:.2f`로 맞춘다.
- [ ] 줄바꿈 + 자리수를 한 번에 하려면 `print(f"{c}\n{a:.2f}\n{b:.2f}")`가 가장 깔끔하다.
- [ ] 줄마다 입력되면 `input()`을 여러 번, 한 줄에 같이 오면 `split()`을 쓴다.
- [ ] 문자열 문제는 `input()` 그대로 쓴다. 계산할 때만 `int()`, `float()`이 필요하다.
- [ ] "순서를 바꿔 출력"은 변수를 바꾸는 게 아니라 `print` 순서만 바꾸면 된다.
- [ ] 값을 진짜 맞바꿔야 하면 `s, t = t, s` 한 줄이면 된다(swap).
- [ ] `split("문자")`로 공백이 아닌 기준으로 자를 수 있다. 예: `split(":")`, `split("-")`, `split(",")`
- [ ] 기준으로 쓴 문자는 결과에서 사라지고, 구분자도 따옴표로 감싼다.
- [ ] 구분자만 바뀔 뿐 그 뒤는 똑같다. 조각은 문자열이므로 계산하려면 `int()`가 필요하다.
- [ ] 공백 기준은 `split()`(빈 괄호)이 안전하다. `split(" ")`는 빈 조각이 생길 수 있다.
- [ ] 구분자가 없으면 안 잘리고 통째로 하나가 된다. 에러가 안 나니 주의!
- [ ] 값이 2~3개면 `arr[0]`보다 `h, m = ...` 언패킹이 읽기 좋다.
- [ ] **계산에 쓰는 값만** `int()`로 바꾼다. 그냥 출력만 할 값은 문자열로 두면 앞의 0이 보존된다.
- [ ] `int("05")`는 `5`가 되어 `13:5`처럼 형식이 깨진다. 주의!
- [ ] 정수 자리수 맞추기는 `:02d` (0으로 2칸 채우기), 소수점은 `:.2f`.
- [ ] f-string에서 `:`은 중괄호 **안**이면 출력 형식, **밖**이면 그냥 글자다. `f"{h}:{m}"` ✅
- [ ] 문제의 **제한 조건**을 봐야 `% 24` 같은 처리가 필요한지 알 수 있다.
- [ ] f-string과 `format()`은 **둘 중 하나만** 쓴다. `f"{}".format(...)`은 SyntaxError다.
- [ ] f-string의 `{}` 안은 비워둘 수 없다. `format()`을 쓸 때만 `{}`를 비운다.
- [ ] `format()`에 list를 통째로 넘기면 `IndexError`가 난다. 원소를 하나씩 넘겨야 한다.
- [ ] 순서를 바꿔 출력할 땐 `mm, dd, yyyy = ...`처럼 **이름을 붙이면** 실수가 줄어든다.
- [ ] 자리만 옮기는 문제는 `int()`를 쓰면 안 된다. `09` → `9`가 되어 오답!
- [ ] 입력 구분자(`-`)와 출력 구분자(`.`)가 다를 수 있다.
