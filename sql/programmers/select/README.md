# SELECT

출제 빈도 낮음, 평균 점수 높음. 조건에 맞는 레코드를 원하는 순서대로 고른다.

앞쪽은 한 테이블에서 `WHERE`, `ORDER BY`, `LIMIT`로 끝난다. 아래 문제는 폴더 이름과 달리 다른 문법을 쓴다.

- `서울에 위치한 식당 목록 출력하기`, `업그레이드 된 아이템 구하기`: JOIN과 집계
- `오프라인/온라인 판매 데이터 통합하기`: UNION
- 대장균 문제(`대장균들의 자식의 수 구하기`부터 `멸종위기의 대장균 찾기`까지): 이 순서 그대로 이어서 푼다
