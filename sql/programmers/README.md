# 프로그래머스 SQL 고득점 Kit

문법은 [SQL 문법 정리](../SQL_문법.md)에 모아 두었다.

문제를 풀 때는 해당 파트 안에 문제 이름 폴더를 만들고 `solution.sql`을 둔다. 목록의 체크박스는 그 폴더가 생겼을 때 표시한다.

```text
select/문제 이름/solution.sql
```

| 파트 | 출제 빈도 | 평균 점수 | 문제 수 |
|---|---|---|---|
| [SELECT](select/README.md) | 낮음 | 높음 | 33 |
| [SUM, MAX, MIN](sum_max_min/README.md) | 보통 | 높음 | 10 |
| [GROUP BY](group_by/README.md) | 보통 | 보통 | 24 |
| [IS NULL](is_null/README.md) | 낮음 | 보통 | 8 |
| [JOIN](join/README.md) | 높음 | 낮음 | 12 |
| [String, Date](string_date/README.md) | 낮음 | 낮음 | 19 |

JOIN이 출제 빈도가 높고 평균 점수가 낮다. SELECT로 쿼리 작성 순서에 익숙해진 뒤, GROUP BY와 JOIN에 시간을 더 둔다.
